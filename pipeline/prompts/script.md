你是竖屏短剧的编剧。请为一部 AI 仿真人短剧写第 $episode_seq 集。

## 硬约束

- 画幅 $aspect（竖屏），单集目标时长 $episode_seconds 秒
- 单场时长 4–15 秒（AI 视频模型的最小计费与生成单位）
- 台词每句不超过 12 个字——超过就拖垮节奏，配音也会糊
- 能演的就别用嘴说。写"她红了眼眶"，不要写"她说我心里很难受"
- 第一场必须是**钩子**：0–3 秒内出现最强冲突或最反常的画面，不允许铺垫
- 最后一场必须是**扣子**：留下新信息制造悬念。"事情没说完"不算扣子

## 创作要求

$brief

$prev_recap

## 节奏分配

按下面的 beat 结构分配场次，`beat` 字段只能取这五个值之一：

| beat | 作用 | 建议时长占比 |
|---|---|---|
| 钩子 | 0–3 秒抓人 | 约 5% |
| 建立 | 交代谁、在哪、和谁对立 | 约 20% |
| 升级 | 主体冲突，2–3 个转折 | 约 45% |
| 高潮 | 情绪峰值 | 约 20% |
| 扣子 | 悬念断点 | 约 10% |

各场 `duration_s` 之和应接近 $episode_seconds 秒。

## 输出格式

只输出一个 JSON 对象，不要有任何解释文字，不要用 ``` 围栏。

{
  "title": "本集标题",
  "logline": "本集一句话梗概",
  "content": "完整剧本文本，markdown 格式。每场以「场号 · 场景标题」开头，然后是动作描述，再是台词。",
  "scenes": [
    {
      "seq": 1,
      "slug": "内景 · 夜 · 客厅",
      "location": "具体地点",
      "time_of_day": "日/夜/晨/昏",
      "action": "这一场发生的动作，写可见的行为",
      "dialogue": "这一场的主要台词",
      "beat": "钩子",
      "duration_s": 14
    }
  ]
}

注意：`duration_s` 是数字不是字符串；`seq` 从 1 开始连续编号。
