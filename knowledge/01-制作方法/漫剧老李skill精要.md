# 漫剧老李 Skill 精要（增量吸收版）

> 来源：github.com/lixiaoxiao9888-create/manju-laoli-skill（MIT，V6.9.8，2026-10-14 学习）。
> 定位：只收录我们知识库**还没有**的方法论，并与我们管线（dsh-film：entities→refs→storyboard→firstframes→video）逐项对照——每条带「怎么做 + 为什么 + 与我们做法的对照/迁移方向」。已有内容（三视图禁用、子空间扩图、否定约束无效、4.1字/秒、建筑设定章、场景侧视图、站位一行式、运镜三段式等）不重复收录。

## 概述（10 行）

1. 「漫剧老李」是给 AI 助手执行的 AIGC 短剧/漫剧全流程 Skill，41 个规则库文件 + 4 个校验脚本，MIT，1198 星。
2. 架构：Asset-First 六阶段 P0 立项锁 → P1 五阶门控剧本 → P2 数字资产包（出图锁定）→ P3 空间调度分镜 → P4 投喂生成 → P5 质检。
3. 核心理念「资产图先于分镜、无图不进分镜」与我们「资产先行」一致，但它把它做成了硬门禁（门禁 3/4：@锚点无已锁定资产图即阻断）。
4. 最大特色是**锁文化**：模型版本锁（A）、画幅锁（B）、交付形态锁（C）、段缝锁（D），四锁未指定不动笔。
5. 第二大特色是**机检门禁**：出稿必跑 `validate_prompt.py`，C1~C20 条目级扫描（时长/套话/镜长雷同/语气错位/摆位必入画/首镜锚定/禁令失效…），FAIL 清零才交付。
6. 第三特色是**拉片闭环**：每条规则都有「实测病灶 → 铁律 → 机检判据」三段身世，规则从废镜里长出来。
7. 投喂主格式是七段式：【画幅风格】【场景资产】【核心人物】【站位声明】【时间轴分镜】【音效】【强制禁止项】+ 接续状态尾行。
8. 与我们管线高度同构：他们的 P2≈我们的 refs 阶段，P3/P4≈storyboard+firstframes，P5 质检≈我们的 prompt_review + 人工验收。
9. 我们没有的：机检脚本化、前置锁机制、段缝末态双保险、语气位规范、FACS 表情配方体系、人物账/首镜锚定纪律。
10. 我们有而它没有的：成本账本、领域事实溯源（F-xx）、出图前逐实体审查器、DB 状态机门禁（见文末专节）。

## 一、前置锁机制（A 模型版本 / B 画幅 / C 交付形态 / D 段缝衔接）

- **怎么做**：四锁是每个任务的第 0 步，A/B 未指定 = 任务不开始（停下询问，禁止默认），C 未指定默认「两者都交付」不阻塞，D 仅多段任务强制。锁定后全流程（提示词模板、API 参数回填、构图、质检）一律按锁值执行，禁止被示例/模板带偏。
- **为什么**：所有「画幅不对」「版本语法混写」类返工的根因都是「默认值替用户做了决定」。锁把不确定性前置到成本为零的时刻。
- **对照**：我们有唯一的「剧本人工门禁」，没有画幅/模型档位的前置锁。我们刚定 16:9 生成——正是 B 锁场景。
- **迁移**：① 给我们的 P0/立项加「画幅锁 + 模型档位锁」（`pipeline_defs` 的 script 阶段前置一个 lock 检查，`human_approval` 同款机制）；② **画幅锁思想强化建筑锁**：建筑设定章是「内容层公共元素锁」，画幅锁是「参数层全局锁」——两者可统一为一个「项目常量表」（model / aspect_ratio / 建筑设定 / 风格基调），所有 stage 生成时注入、审查器逐项校验；③ D 段缝锁对我们是**空缺**——我们的续接链（多段视频）目前没有段缝衔接方式的前置决策。

## 二、五阶门控剧本（Gate 1~5）

- **怎么做**：动笔前过五道门——① Premise：30 字前提公式（主角+欲望+不可抗力+失败代价）+ 黄金 3 秒钩子四选一（极端悬念/认知反差/情绪爆发/视觉奇观）；② Structure：单集 30% 铺垫 / 50% 冲突 / 20% 爆发，结尾卡在决策关头前一帧；③ Beat Sheet：场次存在性法则（删掉不影响后文的场即删）+ 每场因果链（目标→阻碍→升级→转折→不可逆新局面）；④ Worldview：时代/战力天花板/关系图；⑤ 专业剧本页排版。
- **为什么**：我们的「待批」门批的是**成品稿**，五阶门控把审查拆到**半成品**——前提烂就毙前提，不浪费后面的排版劳动。
- **对照**：我们只有一个剧本门禁，粒度粗。
- **迁移**：把我们剧本阶段的验收清单升级为五问（钩子是什么？三幕比例对吗？有可删的场吗？世界观封顶了吗？），成本几乎为零——纯 prompt/模板改动。

## 三、七段式投喂提示词与出稿机检（C1~C20）

- **七段式结构**（唯一权威段序）：【画幅风格（含 model=）】→【场景资产 @SCN】→【核心人物 @CHR】→【站位声明】→【时间轴分镜（每镜行尾原生带「。声音：…。台词：…。」）】→【音效】→【强制禁止项（只装负面清单）】；末镜后必带【接续状态】尾行。
- **机检 C1~C20（部分高价值条目）**：
  - C1~C3 时长/切镜/版本语法；C4 画幅回填；C5 七段式完整性；
  - C11 接续状态禁套话（「严格继承」是工作流口吻，不是画面）；
  - C13 镜长雷同门：同段 ≥4 镜且同值镜长占比 ≥70% 即告警（节奏呼吸占完播率 30% 权重）；
  - C14 OS/VO 声画分离与配额；
  - C15 拉伸凑时门：无台词氛围镜 >5s、纯氛围段 >10s 告警；总时长允许比剧本标注短至 -25%；
  - C16 语气位错位/缺失；C17 摆位必入画；C18 首镜锚定/姿态回退/视线黏道具/特写装空间事件；
  - C19 禁令失效五判据；C20 单主体锚定/悬空指代/抽象形态。
- **为什么**：人读规则先行、机检兜底，两者不互相替代。他们每条机检都来自实拍废镜，判据是拉片反馈的固化。
- **对照**：我们有 `tools/prompt_review.py`（建筑一致性 + 逐实体审查），但只管 refs 出图，**没有投喂稿级机检**；我们的分镜五锁在 storyboard 阶段有 LLM 自检，无代码级扫描。
- **迁移**：照 C 系列给我们的 firstframes/video prompt 阶段写一个 `tools/prompt_machine_check.py`（正则可拦：套话接续状态、镜长等分、无台词镜超 5s、画面段混入声音词、裸禁令词、并列主体句式、悬空指代词）。工作量：**中**。这是全清单里最值得抄的一条。

## 四、段缝锁与末态继承双保险（我们续接链急需）

- **怎么做**（D 锁三选一，可叠加）：
  - ① **末态双保险**（默认）：【接续状态】写「谁+在哪+什么姿态+关键道具状态」的具体末帧画面（❌「角色动作与空间位置严格继承」是套话，模型零记忆继承不了任何东西）；同时**按上一段结尾状态另绘一张段缝分镜参考图**，作为下一段首镜依据——文字+图锁双保险，缺一不可。
  - ② **换机位硬切**：段缝两侧强制换机位/景别，把两段做成剪辑关系而非「一个镜头掐成两截」；禁同机位硬接。
  - ③ **空镜过渡**：1~2s 带戏剧任务的空镜（情绪空镜+BGM / 音效桥声音先入 J-cut / 时空转场），单集 ≤3 处。
  - 附：**跨段蒙太奇默认**——段与段是独立生成的剪辑关系不是连续拍摄关系，跨段位置不一致默认蒙太奇直切；前段尾拍要为后段登场元素埋钩子（剪影/视线指向/声音预告）。
- **为什么**：模型每段零记忆，段缝处必然跳切断层；错误做法是用上段尾帧截图当下段首帧硬拼。
- **对照**：我们的续接链目前靠「接续状态文字 + 首帧关键帧」，接近 ① 的文字半边；**没有段缝参考图**这一半，也没有「换机位」纪律。
- **迁移**：给 stage_firstframes 的段缝镜（下一段首镜）强制生成/复用一张「上段末态」关键帧图（我们本来就是图生视频，这比 Seedance 参考图模式更顺手——**我们做这个更便宜**）。分镜阶段给段缝两侧标注接缝式别。工作量：**小~中**。

## 五、对白语气位（官方对白三要素之三 HOW THEY SOUND）

- **怎么做**：台词统一写 `台词：【角色（语气）："…"】`。语气按四维（情绪色/力度/音质/节奏）写，每句 ≤3 词，允许演进 `（压抑→破防）`，禁空泛结果词（开心/难过/生气）。
- **分流判据一句话**：**麦克风能录到的 → 语气位；摄像机拍得到的 → 画面段**。「嘶哑/冷笑」写进画面段会被模型当视觉信息渲染成「一张冷笑的脸」（错位比丢失更坏）。
- **配套**：① 声音层豁免反形容词（声音没有肌肉动作，可写「嘶哑」「气音」），但仍禁结果词；② **道具动作与语气一致**：闲适把玩只配慢悠悠语气，宣判语气必须换攥紧/捏住（实测宣判词配「把玩玉佩」出戏）；③ 语气档联动语速：气音/一字一顿 → 慢档 <3.5 字/s，急促 → 快档 >5 字/s（连续 ≤3 秒）——语气参与镜长预算计算。
- **对照**：**空缺**。我们视频提示词的台词只有「谁+说什么」，没有 HOW THEY SOUND。
- **迁移**：改 storyboard 阶段的台词字段模板 + 写入视频提示词规范；语速联动并进我们的台词字数×时长表（我们 4.1 字/秒，它 3.5~5 字/秒区间，兼容）。工作量：**小**。

## 六、人物账连续·摆位必入画 + 首镜锚定四铁律

- **怎么做**：
  - **摆位必入画**：站位声明里摆了位的每个人，本段镜行至少带到一次（正拍/焦外/全景/反应均算），给不了镜头就写明 `段末离画·去向`；重新入画要交代方式；相邻段没写移动的人站位不漂移。实测病根：段尾 4 人在堂屋，下段 3 镜只拍 2 人，另外 2 人整段蒸发。
  - **首镜锚定**：每段第 1 镜必须至少一人入画（人名或注明归属的身体局部），空镜开场须声明且每段至多 1 镜。实测：首镜无锚 → 出片「只有一张床」。
  - **景别三一致**：特写只承载单一局部主体，空间级事件（暴雨砸漏房顶）由中景以上承载，禁「特写+顶拍+全屋事件」混装。
  - **姿态延续**：撑起/坐起一旦发生，后续镜必须「保持撑坐」或写明跌回过程，禁无声回退。
  - **视线指派**：说话镜写明「目光落在 XX 脸上」；持道具说话必写「视线不落在道具上」（道具最抢视线，模型默认让角色盯道具）。
- **为什么**：全部来自「重生70」EP01 实拍废镜拉片；每条都有用户原话佐证。
- **对照**：我们的分镜表有站位与出场字段，但没有「每个摆位者必须被镜头带到」的验收；首帧出图由 LLM 自由决定第一镜内容。
- **迁移**：① 写进 storyboard 阶段的分镜规范（LLM 自检清单加 4 条）；② `prompt_review.py` 或机检脚本加「站位人名 × 镜行文本」交叉扫描。工作量：**小**。

## 七、禁令失效三改法 + 栏目纪律（比我们的「否定约束无效」细两档）

我们已收录「否定约束无效 → 改肯定式」。老李的增量为：

- **三改法**：高关联视觉概念（发光/笑/空镜）必须 ① **换词**——被禁词根在提示词**任何位置**（含禁止项栏）零出现，改正向描述；② **主体优先句式**——每段镜 1 第一个分句即人名/身体局部/「画面主体：」，环境前置词开头（"土炕上…"）会诱导空场景开场；③ **触发器移除**——诱发被禁效果的动作/构图本身换掉（道具不靠近任何光源，而不只是「不写光照」）。
- **反光道具零光效描写**：光斑/受光/照射/映出/倒映类从句一律不写——模型不理解「反射」，会把「映出火苗」读成光源出现在道具上（实测玉佩像打火机点了一簇火）；只写材质本色「玉面呈青玉原色」。**连正向写光都会点火**，比我们「否定无效」结论更深一层。
- **栏目纪律**：【强制禁止项】被模型当「规避清单」读——正向指令写进去两头不生效；否定式禁令也禁入（词根=画面词）。该栏只装三类纯负面：画面（变形/多指/水印）、文字、音频。
- **抽象形态删除判据**：**这句里每个词都能画出来吗？画不出来的就是形容词——删掉。**「漏雨成线」→「雨滴砸在手背上溅开」；「手指轻蜷」→ 直接删。
- **对照**：我们有 FRAME_SUFFIX 纯影像句（肯定式字幕防烧入）——正是「换词改肯定」的实践，但我们没有「词根零出现」「光效正向描写也危险」「禁止项栏目纪律」三层。
- **迁移**：把「每镜可画性判据 + 反光道具零光效 + 禁止项只装纯负面」写进 `pipeline/prompts/` 各模板与图片提示词技能；审查器加「光斑/映出/倒映词」扫描。工作量：**小**。

## 八、首镜单主体锚定与具象化（防「两张脸」）

- **怎么做**：① 首镜锚定句只许**一个具名主体**，禁「X 与 Y 同框」并列句式——模型把并列名词+「同框」读成两个主体，实测同一人的手与脸被渲染成两张脸；身体部位一律「她的一只手」从属出现；确需两人同镜由站位声明具名双主体承载。② 指代词必须带归属：「这只手」无先行词 → 模型自己补一个头。
- **对照**：空缺。我们的首帧提示词无单主体纪律，群像镜有此风险。
- **迁移**：storyboard 首帧提示词规范加两条禁写；机检可正则拦「与.{1,6}同框」「这只/那张」。工作量：**小**。

## 九、4 View 资产板与《资产图册》台账

- **怎么做**：
  - 角色 4 View = 左区头部近景/面部特写 + 右区无头全身三联（正面/90°侧面/背面），16:9 白底；五官 10 项（脸型/眉/眼/瞳色/鼻/唇/下颌/耳/标志特征/肤色）+ 服装材质 6 项（面料/纹理/垂坠/做旧/金属扣具/缝纫）+ **性别锚点**（面部特写句必须以「X~Y岁男性/女性（身份代称）」收尾，只写身份代称模型会自行推断性别导致漂移）。
  - 场景资产图三部分：**母版**（纯基准图）+ **功能图**（文戏机位调度版/战斗站位版二选一）+ **拼接图**（左 2/3 高空鸟瞰透视 + 右 1/3 正/背/左/右四格等高）——功能图管机位，拼接图管长相；交叉可定位（右格内容必须能在左鸟瞰找到对应位置）否则废图重出。
  - 资产图一律 16:9 横版，与成片画幅**解耦**。
  - 《资产图册》：CHR/SCN/PRP 全附参考图 + @短锚点，是分镜/投喂的唯一事实来源；@锚点无已锁定图 = 阻断。
- **对照**：我们的 refs 阶段已做角色/场景/道具分批出图 + @锚点思想（接近）；但我们**没有拼接图**（我们的场景侧视图是单视角），没有「性别锚点」，没有「分批确认门禁 2」的逐批锁定。
- **迁移**：① 四格拼接图可作为多房间场景的替代/补充方案（与我们的建筑设定章互补：建筑章管公共元素一致性，拼接图管单场景长相）；② 「性别锚点」一句话直接抄进 entities 模板；③ 资产图 16:9 解耦——与我们现状一致，确认即可。工作量：**小**（性别锚）/ **中**（拼接图）。

## 十、语速三档与时长守恒（补充我们的 4.1 字/秒表）

- **怎么做**：三档——标准 3.5~5 字/s / 慢速重音 <3.5（金句一字一顿）/ 快速爆发 >5（连续 ≤3 秒）；只数可发音字符，标点另算停顿（逗号 0.1~0.3s，句末 0.3~0.6s）；单句 >24 字强制拆 2~3 镜（每镜 ≤18 字）；金句后强制 0.3~0.8s 无对白发酵气口。
- **时长守恒**：总时长由内容倒推，允许比剧本标注短至 -25%，严禁拉长氛围镜凑满；钩子台词必须落在全片 00:00-00:05。
- **对照**：我们已有字数×时长表（4.1 字/秒单值），没有分档、没有标点停顿预算、没有「钩子前置」硬约束。
- **迁移**：语速表升级为三档区间 + 标点停顿；storyboard 阶段加「黄金 3 秒钩子落首镜」检查。工作量：**小**。

## 十一、VO/OS 旁白独白编织（我们完全没有的维度）

- **怎么做**：① 篇幅卡口：VO+OS 占声音容量 ≤30%，60~80 字/分钟（15s 段 ≤20 字）；② **OS 声画分离红线**：内心独白发声时画面角色必须闭口（画面段写闭口证据），绝不用锁口型台词通道；③ VO 冷漠审视法则：把旁白删掉，画面信息量不得减少——复述画面的旁白删；④ 五类正当用途（点题转折/立人设/委屈账/时间锚/信息差），四条禁令（禁交代设定/禁复述画面/禁替代冲突/禁连排贴断章）。
- **对照**：空缺——我们的短剧暂无旁白，但悬疑题材迟早用。
- **迁移**：收录待用；做旁白时按此规范。工作量：暂缓（记录级）。

## 十二、其他要点速记

- **镜长节奏铁律**：正确顺序 = 剧情 → 情绪节拍 → 时长，禁「段长÷镜数」机械等分；镜长覆盖 ≥3 个取值、快慢呼吸交替；爆发镜快切、金句镜留白。与我们「景别跟情绪走」同源，补了时长维度。
- **改动后复验三步闭环**：局部验证 → 七项联动冲突检查（伏笔/角色/信息量/因果/资产/时长/画幅）→ 全量重跑；修改交付必附《改动复验报告》，未附=未完成。**迁移**：我们改 entities/分镜后目前靠人工记忆，可把它做成 verify.py 的提示或 checklist。工作量：**小**。
- **示范句验证纪律**（规则层防毒）：正例只准从实拍通过产物回收【实证】；新造句标【待验证】且禁入机检修复文案；修复建议只写判据不造句。**迁移**：我们写知识库条目时的「实测来源」标注要求与此同构——已有意识，可明文化。
- **微步进切片**（高密度动作段）：0.5~1.0s/片，每片四要素（运镜动词+力学动作+双色粒子+环境受力）；双人混战必须给每方成套锚定（粒子色+材质+轨迹），禁只给一个颜色。武打类，当前题材用不上，记录。
- **12 节拍情绪曲线**：0~10 分量化 12 个节拍点，第 9 节拍必须 9.5+ 终极反杀；波峰 ≥9.0 不得少于 2 次，禁止 5~6 分平铺。可与我们的「高爆结构」互补使用。
- **三条摄影法则**（可并入我们的运镜规范）：Fincher 法则（摄影机默认静止，主体状态改变才跟随，速度 1:1 同步）；Spielberg 法则（观众任何一秒都清楚「主角在哪/威胁在哪/出口在哪」）；黑泽明环境压力法则（全场由一种主导物理环境贯穿）。默奇剪辑权重：情感真实 51% > 剧情推进 23% > 节奏 10% > 视线引导 7%。
