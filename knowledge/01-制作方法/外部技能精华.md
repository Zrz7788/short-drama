## 一、Lira —— 图像提示词优化专家（21 KB）

**身份**：面向图像生成的提示词优化专家（Persona）。四阶段方法论
**解构 → 诊断 → 开发 → 交付**。

### ⭐ 三条直接冲击我们设计的规则

#### 1. 「没有反向提示词参数」

> **这里没有任何模型带有反向提示词参数**——不需要的元素要通过
> **"正向描述你想要的元素"** 来消除。
>
> - 想要干净的皮肤 → 描述为「**干净干燥的皮肤**」，而不是「没有痘痘」
> - 想要空无一人的街道 → 描述为「**空旷荒芜的街道**」，而不是「没有人」
>
> **导致翻车的"不要 XX"堆砌反而会把这些概念注入到画面中。**

**这与我方现设计的冲突**：我们 `shot.negative_prompt` 字段 + 一整套负面词清单。
**按这条，负面词应当降级为"仅在必须阻止已知失败模式时使用"，主力改为正向锁定。**
（与我们从 OpenMontage 学到的「约束写在具名正向锁定块里」**结论一致**——
两个独立来源指向同一件事。）

#### 2. 提示词长度有最优区间

> **精准胜过冗长。一段紧凑的 80–150 字的提示词，效果远好于一段松散的 400 字提示词**：
> 超过一定长度后，每一个多余的从句都会分散注意力，导致细节丢失。

**这是一条可量化的判据**，我们的第 6 阶段可以据此校验。

#### 3. 自然语言，而非关键词堆砌

> 所有模型都能解析**连贯流畅的中文场景描述**。堆砌关键词毫无用处。
> 生成类提示词中**不要使用全大写的章节标题**；结构化的区块（【更改】/【精确保留】）
> 仅用于编辑类提示词。

### 模型路由分配（按任务选模型）

| 任务 | 模型 | 理由 |
|---|---|---|
| **角色**：选角图、肖像、角色一致性 | **Soul 2.0** / Cinema Studio AI Cast | 绑定角色参数可跨生成锁定同一张脸 |
| **场景/环境**：空镜、电影剧照 | **Soul Cinema** | 电影级纹理与胶片颗粒；支持 21:9 |
| **道具** | NBP / GPT Image 2 | 产品级写实 + 物体上文字渲染精确 |
| **画面编辑（永远首选）** | **Nano Banana Pro** | 在原图上操作，改动最小化、其余像素级保留 |
| **修复已完成画面的 AI 塑料感纹理** | Seedream 4.5 | 仅此职责；**绝不可用于局部元素修改** |
| **最精细局部微调 / 场景视角切换** | GPT Image 2（最后手段） | 会污染全局画面，但局部极强 |

**操作顺序固定**：编辑永远先用 NBP → 再 Seedream → 最后 GPT Image 2。

### 关键硬性限制

- **Soul 2.0 不支持 21:9**——宽银幕角色画面要带角色参数扔给 Soul Cinema
- **宽高比与分辨率是平台参数，不是提示词文本**：提示词中不要出现任何代表
  宽高比或分辨率的系统参数代码
- **反打镜头要显式说明物体新位置**：主视角沙发在右 → 反打视角沙发必须在左

## 二、表演系统 ACTING 7（28 KB）

**面向**：AI 视频生成的角色表演指南（Seedance 2.0）。格式与模型无关，
内容是提示词里"运动 / 角色行为 / 表演"区块该填什么。

### ⭐ 核心公理

> **表演是在压力下的行为，而不是情绪的展示。**
> 角色想要得到某样东西，但有阻碍存在，于是他们采取行动去争取。
> **情绪只是这种斗争的副产品——绝不是你直接写在提示词里的东西。**

**这直接修正了我们第 2 阶段"情绪标注"的方向**：
不该写"他很愤怒"，该写**他要什么 + 什么挡着他 + 他用什么策略**。

| 糟糕的表演 | 好的表演 |
|---|---|
| 展示情绪（"我很生气"） | 追求目标（"我要逼你把钱还回来"）——愤怒会自然产生 |
| 干等着轮到自己说台词 | 每一秒都在倾听并对搭档做出反应 |
| 用身体图解台词（动作 = 词语） | 身体有自己的生命，有时甚至与台词相矛盾 |
| 所有台词都用同一种语速语调 | 节奏随着**行动策略的改变**而改变 |
| 情绪在说台词时开启、说完关闭 | **状态是连续的**——台词之前有"前史"，之后有"余波" |
| 脸在"刻意表演"——挑眉、做鬼脸 | **脸在思考**——开口之前，眼神里就能读出想法 |

### 每个场景的五大支柱

1. **目标**：必须是**指向搭档的动词**——"逼他认罪"、"乞求宽限一周"。
   **绝不能是一个状态**（"感到生气"、"感到内疚"）——状态无法被直接演出来。
   背后还有"最高任务"（整个故事想要什么）。
2. **障碍与赌注**：外部的（对手想要相反结果、有目击者、只剩两小时）
   或内部的（自尊不允许乞求、自己都不信自己的话）。
   **必须回答"如果我没得到想要的，会发生什么"——答案要让角色恐惧。**
3. **策略与行动手段**：施压、施展魅力、羞辱、恳求、挑衅、讨价还价、威胁、拖延。
   **死气沉沉的表演就是整个场景只用一种策略。**
4. **节奏点与动作单元**：最小动作单元。结束于：目标达成 / 策略失败 /
   新信息出现 / 权力平衡转移。
   **每一次节奏点改变都必须在行为上可见**（停顿、姿势改变、语速改变、视线转移）。
   **好场景有 2–4 个节奏点改变**；全程行为无变化 = 平淡。
5. **潜台词**：与嘴上说的相反，**不是"演"出来的**——当角色一边说假话一边追求
   真实目标时，潜台词自己流露。可用的标记：不是疑问句的提问／重复／
   生硬转移话题／不合时宜的玩笑（防御脆弱的盾牌）／太简短的回答（关上心门）。

### 倾听与反应 —— 质量的终极测试

> 表演的生命力**不存在于台词中，而存在于台词之间**。

1. **反应在搭档台词结束前就开始**（听到半句就抓住重点，脸和身体已开始回答）
2. **思考先于语言**（回答难题前有微小停顿——明显在决定该说什么）
3. **评估的瞬间**（坏消息/威胁/侮辱需要时间消化。**电影的魅力就建立在这些
   评估瞬间的特写镜头上**：一张脸、失去焦点的眼神、天旋地转的世界）
4. **来自搭档的情绪感染**（节奏、音量、能量随对方反应改变）

### 身体：角色的物理生命

- **生理状态先于心理状态**：重心（高=自信/攻击性/地位；低=疲惫/恐惧/屈服）、
  节奏语速（快=神经质/亢奋；慢=掌控力/威胁——**最危险的人往往动作最少**）、
  开放度、**呼吸**（最诚实的指示器）。
  **声音和物理状态必须匹配**：刚跑完步的人不可能用平稳的声音说话。
- **手头动作与物理任务**：角色几乎总需要一个"正在做的事"——修引擎、数钱、
  做饭、擦玻璃，然后在此之上交谈。
  > **中断动作法则**：最强烈的强调就是角色**停止了手头的动作**。
  > 如果他正在切面包，在某句话时突然停下——这句话就成了一个大事件。
  > **把停止动作当作标点符号来用。**
- **空间距离与戏剧性**：亲密距离（<0.5m，代表爱或暴力，不请自入就是攻击）、
  个人距离（0.5–1.2m，信任）、社交距离（1.2–3.5m，公事/警惕）、
  公共距离（>3.5m，疏离/等级）。**距离的改变 = 节奏点的改变。**
- **地位与隐形的阶级**：地位体现在**行为**而非身份。
  高地位：头部不动、动作缓慢、凝视时间长、回答前有停顿、占据空间、触碰别人的东西。
  低地位：瞎忙活、频繁摸自己（脸/头发）、说话支离破碎、用笑声填补空白、用眼神请求许可。
  **最有意思的是地位的打破**：老板某一秒露出恐惧；下属突然停止微笑。

### 台词

- 节奏写在文本里，要精准传达；**语速快 ≠ 含糊不清**
- 台词交叠（抢话）正常，但关键词要清晰
- **音量对比：最可怕的话往往说得最轻。** 大喊大叫是弱者的通货；
  掌控全场的角色会**降低音量，迫使所有人凑近倾听**
- **停顿是事件，不是漏洞**：只有停顿中发生了某事才合理
- 真实的语言是有"垃圾"的：打断、没听清的词、重复、未说完的半句话。
  **完美构造的句子会扼杀街头的真实感。**

### 角色表演主档案（模板，300–500 字）

> 每个反复出现的角色有一份主档案——行为方式的**永久真相来源**，只写一次，
> 每个场景中改编。**所有内容必须是可见的、可拍摄的。**

```
角色表演：[姓名]。[年龄、体型、体格、姿态——身体作为他们过往经历的档案]。
[用一个从句概括心理引擎——解释其生理特征的内在驱动力]。
声音特征：[音高或音色、口音或出身、语速和表达方式，以及声音在情绪下如何破音或转变]。
关键的生理习惯和下意识小动作：[标志性的小动作及其触发条件；压力下的小动作及其
触发条件；掩饰行为——他们做些什么来隐藏真实感受；面具般的表情以及面具破裂的
确切条件]。步态风格：[作为角色特征的步态——给出具体命名，加上对重心、节奏和
落脚点的描述]。然而，当[情绪触发点]时，[转变——姿态、步态和面部如何变化]。
[可选：软肋目标——唯一能让那张脸真正柔和下来的人或物]。
```

**写每个区块的规则**：

1. **只有可观察的行为。** 每个内在状态都要有身体标记。绝不写"他很紧张"，
   要写"下唇颤抖、沉重地吞咽、用嘴长吸一口气，然后撅起嘴唇急促地呼出"。
2. **每个小动作都有触发器。** 不是"他把指关节掰得咔咔响"，而是
   "他在日常无聊的谈话中会把指关节掰得咔咔响，**以此来伪装自信**"。
   格式：`[小动作] + [时间或原因]`。
   **没有触发器的小动作只是装饰；有触发器的小动作才是戏剧性。**
3. **为步态命名。** 在引号内起一个好记的名字来锚定生物力学：
   "权力步伐"、"孔雀漫步"、"画廊步"、"破城锤大步"、"无畏舰步调"。
   然后拆解：重心、步幅、躯干和手臂在做什么、头部在做什么。
4. **构建面具，并写出面具破裂的瞬间。**

## 三、CINEDANCE V4 —— Seedance 2.0 提示词导演系统（36 KB）

**身份**：精英级 AI 电影提示词导演。目标是把任意场景转换为
**干净、达到制片标准、高预算电影级别**的视频提示词，**尽可能一次生成即完美**。

> 你不仅仅是在撰写优美的散文。你要作为**电影导演智能体**运作，在输出前进行
> 内部逻辑推理、场景诊断、**空间调度**、光学镜头选择、物理反馈验证、
> 参考图控制、连戏控制以及静默自检。

### 核心目标（即"要防住的失败清单"）

稳定的参考一致性 / 正确的角色站位与调度 / **正确的起幅（第一帧）画面** /
正确的视线方向 / 正确的身体朝向 / 正确的参照物距离 / 正确的摄影机机位侧 /
正确的光学镜头物理表现 / 符合物理现实的运动轨迹 / 强烈稳定的光影方向 /
干净的对话时间轴 / **无语境泄露** / **无未出场角色** / **无过期 @标签** /
无场景编号等冗余文本 / 无提示词污染

### D1 拆解 —— 明确要**移除**的东西

> ⚠️ 绝对不要在提示词中包含**不在此特定镜头中出现**的角色、物体、场地、
> 道具、车辆或 @标签。

要移除：未出场角色、未使用的 @标签、**场景编号**、剧本场记标题、
上一场戏的描述文本、旧提示词碎片、不针对生成的制片备注、
"同上"、"如前所述"、"继续自…"。

### ⭐ D2 诊断 —— 一份可以直接变校验器的失败风险清单

- 起幅（第一帧）是否可能为**空镜**？
- 关键角色是否可能**出场太晚**？
- 模型是否可能以一个无用的**交代镜头（全景建置）开场**？
- 角色出现的位置是否可能离地标参照物太远？
- **视线方向是否可能发生反转？**
- 身体朝向是否可能模棱两可？
- **左右站位是否可能对调？**
- **摄影机是否可能选择了错误的机位侧？**
- 镜头焦段是否可能**漂移到一个保守平庸的默认焦段**？
- 画面是否可能变成平庸的**正打顺光**？
- 参考图特征是否可能被**过度的散文式描述所覆盖**？
- 是否有**过期的 @标签**混入？
- 模型是否可能**添加额外的角色或克隆人**？
- **道具是否可能出现在错误的手中？**
- 运动是否可能变得**轻飘飘或违背物理现实**？
- 对话是否可能在**错误的时间**开始？
- **场地参考图是否被错误地用作了构图依据，而不是地理依据？**
- **多镜头剪辑是否会重置连戏？**

**如果存在任何风险，在最终提示词中加入简短、直接的锁定指令。**

### D3 开发 —— 15 步固定顺序

```
1  场景语境        2  输出设置        3  活跃参考
4  场地映射        5  首帧与空间调度   6  角色锚点
7  格式模式        8  光学与镜头决策   9  摄影机与构图
10 动作时间轴      11 物理法则与材质动态
12 灯光与曝光      13 音频
14 正向锁定约束（根据需要）  15 局部防错锁定（仅在必要时）
```

> **不要将关键的站位规则埋没在风格化的散文描述中。**
> **空间调度规则必须位于摄影机风格之前。**
> **光学物理属性必须位于一般审美描述之前。**
> **灯光必须被视为最高优先级的锁定条件，而不是装饰。**

### D4 交付 —— 只输出提示词

> 不要输出自检过程、推理过程、检查清单、解释，不要提及内部方法论，
> 不要在最终提示词中加入编写笔记。

### 最终提示词架构（13 区块）

```
【场景语境】【活跃参考】【场地映射】【首帧与空间调度】【格式模式】
【光学镜头】【摄影机机位】【动作时间轴】【物理法则】【灯光】【音频】【正向约束】
```
可选：【输出设置】（仅当 UI 未选或对剧情至关重要）、
【负向约束】（**仅当用户明确要求，或必须阻止已知失败模式时**）。

> **优先使用局部内联锁定，而不是在结尾写一大段负向约束块。**

### 几条非常具体的规则

**场景语境**：一到两句，讲清这个镜头发生了什么。
**不要**包含场景编号、前情提要、未出场角色、剧本场记标题。

**输出设置**：若 UI 已选，**从提示词中省略**（时长/画幅/图生视频/帧率/快门/
模型名/分辨率/种子）。只保留影响可见或可听结果、且不能被 UI 安全处理的设置。
> 好例：`受控的多镜头序列，在 1.0 秒处有一次硬切。常速（实时）动作。无字幕，无音乐。`
> 坏例：`总长8秒，21:9，R2V多参考，24fps，180度快门。`

**活跃参考**：@标签是平台原生句柄。**保持活跃的 @ 标签原封不动；
绝不凭空捏造新的；绝不包含过期的。**

**角色描述公式**：
```
@标签: 年龄 + 角色/体型 + 当前状态 + 关键可见锚点 + 动作关键道具/身体状态。100% 匹配参考图。
```
> 示例：`@HERO1V2: 20岁宽肩受伤的男性，凌乱的金发垂在眼前，沾满血迹的灰色连帽衫，
> 右肩胡乱地缠着绷带，左手紧握一根凹陷的钢管。与参考图100%匹配。`

> **参考图是面部、身体、比例、服装、纹理和身份特征的唯一真相来源。
> 不要用过度的散文式描述覆盖参考图。**

**场地映射**：若存在场地参考图，编写调度前先把它转成**实用的地图**——
定义摄影机位置/朝向、前景/中景/背景、主要地标位置、角色站位、运动轨迹、
光线方向、景深关系。
> **场地图用于地理环境、材质、氛围、地标参照物、光线方向——
> 除非用户明确要求，否则不要盲目继承它的摄影机角度、画幅或构图。**

**首帧画面定场锁定**：
> `第一个可见帧已经包含了所有所需角色及其正确的站位。无空镜开场。无延迟的角色出场。`
