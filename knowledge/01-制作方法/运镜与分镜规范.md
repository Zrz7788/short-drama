## 一、⭐ 情绪化运镜十型（最大的收获）

**运镜不是为了动，是为了传递情绪。** 每一种运镜对应一种心理效果：

| 运镜 | 提示词命名 | 传递的情绪 |
|---|---|---|
| 从宽泛视野向核心主体推进，**画面边缘逐渐收缩** | **聚焦式推进** | 逐渐沉浸、**情绪递进**的张力 |
| 从主体近景平稳向后拉开，主体占比缩小 | **抽离式后拉** | 疏离感、释然、时空延展 |
| 沿水平方向缓慢摇动，元素依次进入视野 | **探索式横摇** | 追寻、好奇、不安，暗合未知探索 |
| 与主体保持平行轨迹，始终以主体为视觉锚点 | **陪伴式平移** | 无声陪伴、叙事流动感，**弱化冲突** |
| 从低角度缓慢上升，视野从局部扩展至开阔空间 | **升华式上升** | 崇高、希望、释然 |
| 从高处缓慢沉降，视野从开阔收拢至特定主体 | **压抑式下降** | 压抑、失落、聚焦的沉重感 |
| 以主体为中心环绕旋转，产生动态模糊与眩晕 | **迷幻式旋转** | 混乱、迷幻、情绪剧烈波动 |
| 快速爆发力向前急推或向后急拉，短时间完成压缩/拉伸 | **爆发式急推/急拉** | 突发冲突、紧张爆发，**适合情绪转折点** |
| 伴随轻微自然抖动，随主体移动灵活运镜 | **纪实式手持** | 真实、慌乱、紧张，**弱化"刻意设计感"** |
| 先保持静止，再自然切换为动态 | **静动转换式** | 从平静到涌动、从抑制到释放，**暗合"心理觉醒"** |

**对我们的意义**：`shot.camera_move` 现在填"推"/"摇"，模型只能猜。
应该填**带情绪的命名**（"聚焦式推进"）——它同时是动作描述和情绪指令。

## 二、⭐ 运镜的量化参数（可直接写进提示词）

**这是同类材料里唯一给出可执行数字的。**

| 运镜 | 量化写法 |
|---|---|
| 推 | 缓慢推进，从全景推至中景/近景，**每秒移动 10–15 厘米**，最终聚焦面部/核心细节 |
| 拉 | 快速拉远，**0.5 秒内**从填满画面拉到主体占比 10% |
| 水平摇 | 匀速慢摇，从左至右扫过 **30 米宽**场景，**8 秒内**完成，画面边缘始终水平 |
| 垂直摇 | 快速急摇，从地面摇至天空，**2 秒内**完成，捕捉从脚部到云层的完整轨迹 |
| 移 | 缓慢侧移，与主体保持 **2 米**距离平行移动，**每秒 50 厘米**，主体始终在画面中央 |
| 跟 | 匀速跟拍，与主体步行速度（**约每秒 1.2 米**）完全同步，前后左右偏差**不超过 30 厘米** |
| 升 | 缓慢升空，从腰部高度升至 **10 米**高空，**6 秒内**完成 |
| 降 | 快速下降，从 **20 米**高空直落至主体头顶正上方 **1.5 米**处，**3 秒内**停稳 |
| 旋转 | 快速旋转，**1 秒内**完成 360° 光轴翻转 |
| 环绕 | 匀速环绕，以主体为圆心，保持 **3 米**半径，**每秒转动 30°**，**12 秒**完成一周，始终正对主体 |

## 三、景别 / 视角 / 方向的三张对照表

### 景别与信息量

| 景别 | 描述 |
|---|---|
| 远景 | 主体占比极小，重点呈现环境整体氛围，空间纵深感强，**弱化主体细节**，突出环境包裹主体的关系 |
| 全景 | 完整呈现主体全貌 + 周围核心环境，**主体与环境比例平衡** |
| 中景 | 聚焦主体主要活动区域，兼顾动作细节与局部环境 |
| 近景 | **压缩环境空间**，聚焦主体局部细节，强化观众与主体的近距离感 |
| 特写 | 极致聚焦微小局部，**几乎排除环境干扰**，通过放大细节传递情绪或质感 |
| 微距 | 超近距离拍摄微小对象，局部占据大部分空间，背景高度模糊 |

### 视角的情绪效果

| 视角 | 效果 |
|---|---|
| 俯拍 | 自上而下，清晰展现主体与周围空间的布局关系，**弱化主体的个体存在感**，突出整体秩序或环境的包围感 |
| 仰拍 | 自下而上，强化主体的**向上延伸感**，传递权威感、力量感或压迫感，背景多为天空等向上的环境 |

### 特殊场景拍摄配方（拿来即用）

| 场景 | 配方 |
|---|---|
| 雨景 | **120fps 慢镜头 + 手持微晃**，从肩头移至积水，凸显雨滴涟漪与氛围感 |
| 舞蹈 | **3–5 米半径环绕跟拍（腰高镜头）+ 节奏变速**，突出肢体舒展弧线 |
| 美食 | **50mm + 特写推进（0.5 倍速俯视）**，展现酱汁纹理与食材色泽 |
| 夜景 | **30cm 低角平移 + 15° 上扬（1–2 秒长曝光）**，呈现路灯光晕与车流反光交织 |
| 跑步 | **前跟拍（2–3 米距，肩下角度）+ 动作起伏**，强化力量与速度感 |
| 婚礼 | **85mm + 长焦侧后推进**，从交握的手拉远至花海 |
| 自然风光 | **无人机环绕上升（50m 至 100m，每秒 5° 转）** |
| 昆虫微距 | **1:1 倍率，左右 10° 摇镜**，浅景深虚化背景 |
| 猫咪跳跃 | **跟拍（与猫平齐）+ 快速对焦**，捕捉起跳瞬间 |

## 四、分镜脚本的 10 大模块框架

**核心目标**：让 AI 精准理解创作意图，同时方便把控节奏、梳理剧情。

| # | 模块 | 撰写要点 |
|---|---|---|
| 1 | **镜号** | 顺序编号；嵌套（插叙/回忆）用 `1-1`；增删镜头用 `2-A / 2-B` 避免重编号 |
| 2 | **景别** | 远景/全景/中景/近景/特写/**大特写**；大特写"慎用，避免视觉疲劳" |
| 3 | **镜头运动** | **必须写"速度 + 终点/起点景别"**，不能只写"推镜头" |
| 4 | **画面内容** | ⭐ 核心模块（见下） |
| 5 | **台词/旁白/音效** | 格式：`角色名：【台词内容】（语气）`；音效标"类型+出现时机+音量" |
| 6 | **时长** | **对话镜头每句台词对应 1–2s；有表情停顿再 +0.5–1s** |
| 7 | **AI 风格提示** | 画面风格、画质要求、绘画技法 |
| 8 | **备注** | 转场方式、AI 生成避坑点、后续调整方向 |

### ⭐ 画面内容的撰写公式

```
角色状态（动作 + 表情）
  + 场景细节（环境元素 + 布局）
  + 光影氛围（光线类型 + 色调）
  + 关键道具（位置 + 状态）
```

**模糊 → 精准的改写示范**（教学价值很高）：

> ❌ 模糊：「主角在房间里开心」
>
> ✅ 精准：「主角（**17 岁少女，双马尾，校服**）坐在书桌前，
> **双手握拳放在胸前，嘴角上扬露出虎牙，眼神明亮**；
> 房间布局：**左侧书架摆满漫画，右侧窗户透进暖黄色夕阳，书桌上放着一杯冒着热气的牛奶，
> 桌角有一个粉色闹钟（显示 18:30）**；
> 光影：**夕阳斜照，在墙面投下主角的影子，画面色调温暖柔和**」

**四条 AI 适配要点**：

1. **明确角色设定**：首次出现标注年龄/外貌/服饰，后续写"**延续前镜设定**"
2. **环境细节具象化**：不写"科幻实验室"，写"科幻实验室，**墙面布满蓝色数据流屏幕，
   中央有圆形实验台，台上放置透明培养舱，舱内有淡绿色液体**"
3. **光影色调明确**：标注"光线类型（自然光/人造光/特殊光）+ 色调（冷/暖/复古）"
4. **动作细节精准**：不写"主角跑步"，写"主角**弯腰奔跑，双臂前后摆动，
   校服裙摆向后飘动，头发凌乱，脚步急促**"

> **这与《拾音人》的"情绪外化为身体细节"是同一条原则，而且给了完整的改写示范。**

## 五、背景提示词的 6 要素公式

```
风格定位 + 场景主体 + 时空条件（时间 + 天气）+ 氛围情绪 + 细节元素 + 镜头/光影
```

| 要素 | 说明 |
|---|---|
| 风格定位 | 视觉基调的基础锚点（国漫古风/赛博朋克/二次元卡通/写实科幻…） |
| 场景主体 | 明确具体场景类型（悬崖边/竹林/赛博街道/宗门洞府…） |
| 时空条件 | **时间（白昼/黄昏/深夜）+ 天气（晴天/雨夜/雾天/雪天）** |
| 氛围情绪 | 通过色调与光影传递（凝重/温馨/诡异/宏伟/紧张） |
| 细节元素 | 增强真实感与辨识度（飞檐/霓虹灯牌/灵石微光/悬浮车） |
| 镜头/光影 | 构图与视觉层次（低角度仰拍/电影级侧逆光/浅景深） |

**通用模板**：
```
{风格}，{场景主体}，{时间+天气}，{氛围}，{细节元素}，{镜头+光影}，高细节，电影级渲染。
```

**示例（古风仙侠·洞府疗伤）**：
> 国漫仙侠风，昏暗的洞府石壁，深夜，零星灵石发出微光，缠绕绷带的石床，
> 周围漂浮紊乱的灵气光点，电影级侧逆光，浅景深，氛围凝重，高细节。

## 六、风格体系（4 大类 × 细分）

每种风格给的是**核心风格词 + 画面元素 + 镜头与节奏 + 角色塑造**四件套。

| 大类 | 细分 |
|---|---|
| **日系动漫** | 热血少年漫（线条硬朗、高饱和、低角度仰拍、快速跟拍）／治愈系少女漫（线条柔和、马卡龙色、平视俯拍、**节奏缓慢平稳穿插空镜**）／暗黑系悬疑漫（冷色调、强对比阴影、**节奏忽快忽慢穿插主观镜头**） |
| **国漫** | 古风玄幻（中国红/墨黑/鎏金/青蓝、全景+慢镜头、**节奏舒缓穿插空镜展现东方意境**）／现代都市 |
| **美漫** | 超级英雄（线条粗犷、广角+低角度仰拍）／美式卡通 |
| **其他** | 赛博朋克、写实科幻、奇幻魔幻 |

## 七、可以直接进我们流程的改动

| 我们的现状 | 应该改成 | 依据 |
|---|---|---|
| `camera_move` 只填"推"/"摇" | **填带情绪的命名**（"聚焦式推进"/"压抑式下降"/"静动转换式"） | §一 |
| 运镜没有速度/距离参数 | **加量化**：速度（每秒厘米）、距离（米）、时长（秒）、角度 | §二 |
| `camera_angle` 只有"平视/仰视/俯视" | **加情绪效果**（俯拍弱化主体、仰拍强化权威） | §三 |
| 没有特殊场景配方 | 建一张**场景→拍摄配方**对照表（雨景/夜景/跑步/舞蹈…） | §三 |
| 分镜表没有"AI 风格提示"和"备注" | 补上（模块 7、8） | §四 |
| `description` 写得笼统 | 按**四段公式**写：角色状态+场景细节+光影氛围+关键道具 | §四 |
| 后续镜头重复写角色特征 | 写"**延续前镜设定**" | §四 |
| 台词时长靠估 | **每句台词 1–2s，表情停顿 +0.5–1s** | §四 |
| 场景描述没有统一公式 | 用 **6 要素公式** | §五 |
| 风格靠自由发挥 | 从**风格体系**里选一类，按"风格词+画面元素+镜头节奏+角色塑造"四件套写 | §六 |
