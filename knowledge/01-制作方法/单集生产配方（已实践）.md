## 一、已验证的取舍（这些**不要再重新讨论**）

| 项 | 结论 | 依据 / 代价 |
|---|---|---|
| **生成画幅** | 16:9 横屏生成 | 竖屏直出会烧字幕（实测 3/14 中招）；横屏容错高 |
| **交付画幅** | **9:16 竖屏**（红果硬要求） | 见 `knowledge/02-模型与成本/红果与备案规格.md` |
| **跨画幅怎么放** | **完整画面 + 上下模糊填充**（`--fill blur`） | 裁切会把人裁没（S12 实测）；模糊填充一点不丢 |
| **分辨率** | **720P**（2026-10-15 实测够用） | 同一镜真出 720P vs 1080P 并排比：手机尺度看不出差别；模糊填充下画面只占 1080×608，720P 源（1280×720）**还要缩小**。1080P 只在"要读字/海报级"时用 |
| **单镜时长** | **4–6 秒**，硬上限 15 秒 | 7–8 秒的长镜出现"道具凭空消失"（S14）、"近乎静帧"（S07） |
| **模型分档** | 正脸/对手戏 → 2.5 旗舰；空镜/背影/手部 → 2.0 标准 | 2.0 便宜 31%，简单镜完全够 |
| **Draft 工作流** | 难镜先 480P 样片（¥0.26/秒），**选中后再出成片** | 样片阶段就能发现语义缺陷（S11 一次验出姿态问题） |
| **字幕** | `tools/subtitle.py` 出 `.srt`（给平台）+ `.ass`（烧录用） | 说话窗口来自**音频实测**，不需要 ASR |
| **烧字幕** | 用 `.ass`，**不要**给 SRT 配 `force_style` | libass 字号是"脚本单位"，会把字放大到半屏（实测） |
| **响度** | `--loudnorm -16`，归一后**再量一次** | 各镜电平差 18 dB；`loudnorm` 单遍是边估边调 |
| **交付容器** | `-movflags +faststart` | 否则 moov 在文件尾，界面/浏览器打不开（实测） |
| **一条铁律** | **ffmpeg 只写工作区**，跨盘交 python copyfile | 写 D 盘必 `Permission denied`，提权也没用 |
| **景别/运镜写法** | 景别给**配方句**（"超清微距特写，皮肤纹理与物体质感增强"），不只写一个词；运镜的**速度/范围自己写数字** | 出处《小蕾知识库分享版》，见 `运镜与走位配方（小蕾知识库）.md`；**配方句已剥掉"运动"与"从哪到哪"**，免得和运镜/静止锁打架（实测 S05 被套上矛盾范围） |
| **多人调度** | 计划用**轨迹图**（第二张参考图：点=初始位置、箭头=方向、绿点=相遇处）+ 声明"生成时不要出现色点与箭头" | 同上；我们栽在站位/走位上最多（S12），**尚未实现** |

## 二、EP002 起手命令序列（照抄即可）

```bash
# ── 0. 素材复用：角色/场景/道具参考图**跨集共用**，EP002 只补新场景
#      （EP001 的 28 张参考图是一次性资产，别再花这 ¥30）

# ── 1. 剧本（agent + short-drama-write 技能）→ 剧集/EP002/剧本.md
python pipeline/stage_script.py --episode-id 2 --from-md 剧集/EP002/剧本.md

# ── 2. 实体 + 3/4. 参考图（只补新增实体）
python pipeline/stage_entities.py --episode-id 2
python pipeline/stage_refs.py --episode-id 2 --phase characters   # 按需

# ── 5. 分镜（agent + short-drama-storyboard 技能）
python pipeline/stage_storyboard.py --episode-id 2

# ── 6. 提示词定稿 → **出片前先过语义闸门（不花钱）**
python pipeline/stage_prompts.py --episode-id 2 --dry-run
python pipeline/precheck.py --episode-id 2          # P01..P08：批注式文字/平躺写平视/器械缺尺度…
python tools/prompt_review.py --episode-id 2

# ── 7. 首帧图（只给需要的镜）
python pipeline/stage_firstframes.py --episode-id 2

# ── 8. 视频：难镜样片 → 看帧 → 成片；简单镜直出
python pipeline/stage_video.py --episode-id 2 --mode draft --dry-run     # 先看张数与金额
python pipeline/stage_video.py --episode-id 2 --mode draft
#    ⚠️ 抽帧看语义风险（姿态/手/文字/双人）**再**出成片
python pipeline/stage_video.py --episode-id 2 --mode final --resolution 720p
python pipeline/stage_video.py --episode-id 2 --mode direct --resolution 720p
#    重出之后必须：--select 3:4   （否则正片里还是旧那条）

# ── 9. 抽帧
python pipeline/frames.py --episode-id 2

# ── 10. 交付：字幕 + 模糊填充 + 响度归一
python tools/subtitle.py --episode-id 2
python pipeline/assemble.py --episode-id 2 --fill blur --loudnorm -16 \
       --srt 剧集/EP002/E02.ass --out D:\dsh-film\assets\final

# ── 收尾体检（都是零成本）
python tools/qc_frames.py --episode-id 2      # 糊/静帧/接缝跳光（筛子，非判决）
python tools/audio_check.py --episode-id 2    # 音轨里有没有人声
python tools/cost_report.py                   # 总账：生成 + 文本 LLM + 对话
```

## 三、出片前的三道闸门（EP001 的坑换来的，**不花钱**）

| 闸门 | 拦什么 | 出处 |
|---|---|---|
| `precheck.py` | 画面文字带镜号批注（S03 烧进画面）、平躺写平视（S02 站着）、嘴唇闭合+穿出物（S04）、器械缺尺度（S06 巨钩）、手部特写缺分指（S08） | 全是 EP001 实亏 |
| **样片看帧** | 姿态 / 手 / 文字 / 双人 —— **机械指标查不出来的那一类** | S02 就是样片阶段能救的 |
| `qc_frames.py` | 近乎静帧（S06/S07/S14）、接缝跳光 | 14 镜 1 分钟 |

> ⚠️ **机械体检是筛子不是判决**：S02/S04 偏暗是景别反差（正常），S05 首尾差大是推镜（正常）。
> 人眼只看筛出来的那几个。

## 四、模型能力边界 → 拍法规避（改提示词没用）

| 模型做不到 | 拍法 |
|---|---|
| 长镜保持小道具（S14 确认书 6 秒内消失） | 关键道具给**近景**；单镜 ≤6 秒 |
| 一镜内换景别（S09 全景→大特写） | **一镜一景别**；不许"全景+推近"同现 |
| 肢体交叠不穿模（S08 手指陷进手套） | 分镜阶段就**别给这种构图** |
| 手指/脚趾解剖 | **裸手裸足不进近景**；手部镜写"五指分指" |
| 织物纹理保持（S07 白单污渍漂移） | 带污渍道具只出现在短镜里 |
| 屏幕数字严格递变 | **别让读数承担连续性** |

## 六、配方怎么更新

1. **踩到新坑**：先在 `pipeline/precheck.py` 的规则表加一条（**必须写"出处"**：
   哪一集哪一镜的哪次亏），再回这里 §1 或 §4 加一行。
2. **决定变了**（比如换了分辨率）：改这里 §1 的结论 + 写明**新依据**，
   不要留两套说法。
3. **每次收工**：跑一次 `tools/cost_report.py`，账和平台账单当场对——
   2026-10-15 那次"充值 400 / 账本 197"的教训就是**从不当天对账**。
