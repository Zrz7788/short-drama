## 一、音色自制与克隆（配音环节直接用）

对应《配音与口型架构》的路线②（reference_audio）与路线③（外部 TTS）：不管哪条路，**先要有目标角色的干净人声样本**。两份 docx 讲的就是这一步。

### 1.1 音色素材制备（《教你如何自制所需人物角色音色.docx》）

以"给叶修做音色"为例的完整流程：

1. **明确目标角色**，找到该角色在网络上**说话的视频片段**（剧cut/直播切片等）。
2. 素材关键要求：**有背景 BGM 也没关系，重要的是单角色说话**——不要多人对话混剪。
3. 视频能下载就下载；不能下载（平台限制）就**录屏**，音质损失可接受。
4. 导入**剪映**处理（人声分离是会员功能；原文档附了一个第三方"剪映绿色版"网盘链接——**来源不可信，不建议使用**，优先用官方或下述替代路径）。
5. 剪映内步骤：
   1. **分离音频**（右键音频分离）
   2. 删掉画面轨，只留音频
   3. 右击 → **人声分离 → 仅保留人声**（去掉 BGM/音效）
   4. 调整说话间隔：**去除多余的静音段**，让样本里句子密集
   5. 导出为 **WAV 或 MP3**

剪映的替代（同等效果）：ffmpeg 抽轨 `ffmpeg -i in.mp4 -vn out.wav` + Demucs/UVR 人声分离，再做静音裁剪——免费、可脚本化，适合批量做多个角色。

### 1.2 音色克隆工具清单（《克隆方法.docx》）

拿 1.1 的样本喂给以下任一工具：

| 工具 | 入口 | 要点 |
|---|---|---|
| **魔搭社区 IndexTTS2**（推荐） | modelscope.cn，搜 "indextts2" | 在线创空间直接跑，**原文标注"运行较快"**；上传音色样本 + 输出文本即可合成 |
| **Noiz** | noiz.ai/explore | **每天 5000 字符免费额度**，日常量够用 |
| **Fish Audio** | fishspeech.net/zh | 原文标注**需要魔法上网** |
| **MiniMax** | minimax 官方 | 商用 API，按量计费 |
| 本地部署 | — | 原文档只提了"本地部署"四个字，无细节；可走 GPT-SoVITS / IndexTTS2 本地版 |

**与管线的衔接**：克隆出的音频 → 路线②作 `reference_audio` 传给 Seedance 让口型对上；或路线③直接混音（口型用 Wav2Lip/MuseTalk）。音色样本制备标准——**单人、≥30 秒干净语音、去 BGM、去静音**。

### 1.3 选型建议（结合我们的配音架构）

| 场景 | 首选 | 理由 |
|---|---|---|
| 仿真人短剧要特定角色音色 | IndexTTS2（魔搭）做样本 → reference_audio 传 Seedance | 口型天然对齐 + 音色可控，见《配音与口型架构》路线② |
| 漫剧/动画风配音 | edge-tts 声线表为主，克隆音色为点缀 | 漫剧不苛求口型，逐句可调更省 |
| 免费额度试水 | Noiz（日 5000 字符） | 零成本验证音色是否贴合角色 |
| 批量多角色 | 素材制备脚本化（ffmpeg + 人声分离），再逐个进克隆工具 | 每角色一次制备，长期复用 |

**坑位提醒**：克隆音色只解决"像不像"，**不解决版权**——用他人角色的声音做商用内容仍有侵权风险；仅限个人学习或已获授权的形象。

## 二、转场提示词库（《电商转场提示词1.xlsx》）

### 2.1 xlsx 实际内容

文件 6.3MB 几乎全是内嵌图（`DISPIMG`），文本只有一组"商品图→产品特写图→转场句"的**电商产品视频三段式示例**：

> 前镜：橙色剑兰花特写（超写实、纯黑背景、柔和自然光、佳能 EOS R5 质感描述）
> 后镜：香水瓶产品特写（浅橙渐变背景、中心对称构图、漫射光突出质感）
> **转场句：以橙色剑兰花为中心，镜头环绕下降，穿过花瓣间隙，平移聚焦到香水瓶，保持动态模糊与金色光斑轨迹连贯**

这印证了已有结论（商品视频转场 = **前一镜的实体元素成为后一镜的入画路径**），即《运镜与分镜规范》"匹配转场"的电商变体：**形状/主体匹配 → 运动轨迹衔接**。

### 2.2 与已有转场知识对照

| 类别 | 已有覆盖 | 本次新增 |
|---|---|---|
| 硬切/叠化/闪切/划镜/画中画/匹配转场 | ✅《运镜与分镜规范》§六之二 | 无新增 |
| 转场句写法（硬切为主、首尾帧锁定） | ✅《Seedance提示词与连续性锁定》《实战技法合集》 | 无新增 |
| **实体穿越式转场**（环绕下降穿过花瓣间隙→聚焦产品） | ❌ | ✅ **新增**：电商/产品视频专用——把前后镜共有的实体（花→瓶上的花）作为穿越通道，用"环绕/下降/穿过+平移聚焦+轨迹元素连贯"三段式写法 |
| **电商产品三段式**（氛围图→产品特写→转场句绑定成组） | ❌ | ✅ **新增**：商品视频的转场不单独存在，必须与前两镜的提示词成组设计 |

已有「转场句」「段缝双保险」覆盖叙事视频；本条补的是**带货/产品向视频**的转场套路，两套场景不同，都保留。

## 三、通义万相 2.2 指南要点（竞品参考，只记差异与可借鉴写法）

我们主力用 Seedance，此文档仅作能力对照与写法参考，不照录。

### 3.1 能力差异（通义万相 2.2 vs Seedance）

| 维度 | 通义万相 2.2 卖点 | 对我们的意义 |
|---|---|---|
| 影视级美学控制 | 光源类型/光线/时间段/景别/构图/镜头/焦段/机位/色调 九大维度词表 | 提示词维度划分与我们《运镜与分镜规范》一致，可互为校验 |
| 动态控制 | 肢体、体育运动、面部情绪的精准稳定生成 | 体育类动作其词表较细（街舞/滑雪/扣篮等 10+ 条），Seedance 大动作若崩可借鉴其描述粒度 |
| 语义遵循 | 多目标生成、复杂空间准确性 | 它主打"指令遵循"，若 Seedance 多人同框串位，可备选测试 |
| 图生视频 | 公式极简：**提示词 = 运动 + 运镜** | 与我们"图生视频只写动态"的结论一致 |

### 3.2 可借鉴的提示词写法

1. **三层公式**：基础 `主体+场景+运动`；进阶 `主体(描述)+场景(描述)+运动(描述)+美学控制+风格化`；图生视频 `运动+运镜`。与我们已有结构一致，无需改管线。
2. **美学控制词前置**：其示例统一把 `光源类型，景别，构图，色调，对比度` 等**标签词放在句首逗号分隔**，再接完整叙事描述——标签先行便于模型解析，我们首帧提示词可沿用此序。
3. **光源类型词表**（其九维中最细的一维）：日光/人工光/月光/实用光/火光/荧光/阴天光/混合光 × 柔光/硬光/顶光/侧光/背光/底光/边缘光/剪影/高对比度/低对比度——比我们现有的更系统，可直接补进《运镜与分镜规范》光线字段词源。
4. **运动描述带幅度与效果**："猛烈地摇摆""缓慢地移动""打碎了玻璃"——运动必须写幅度+速率+作用结果，不许只写动词。
5. **人物情绪单列维度**（怒/惧/喜/悲/惊五条示例，均为"环境+生理反应"式写法，如恐惧=瞳孔放大+汗珠沿太阳穴流下）——与我们 FACS 配方同路，可直接对照复用。

**结论**：通义万相 2.2 无独有能力让我们切换；其价值是一套**组织良好的提示词维度词表**（尤其光源九维），已并入上文 3.2 第 3 条，其余与现有知识库重复，不展开。

### 3.3 与 Seedance 的实操分工建议

| 场景 | 建议 |
|---|---|
| 日常主力 | 继续用 Seedance（成本模型已跑通，见《单集成本模型》） |
| 体育/大动作镜头崩坏时 | 换用 3.2 第 4 条的运动描述粒度重写，仍在 Seedance 内重抽；仍崩再考虑通义万相出该镜头 |
| 多人同框串味/串位 | Seedance 失败 2 次以上时，通义万相 2.2 的"多目标生成"值得一测（标注：未实测，仅凭其官方宣称） |
| 光线/氛围不达标的画面 | 先套 3.2 第 3 条光源九维补写提示词，不换模型 |
