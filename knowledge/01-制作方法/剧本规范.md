# 剧本规范

> ⚠️ 与 `竖屏短剧结构模板.md` 一样，本页的格式约定是**工作假设**，不是验证过的行业标准。
> 它的作用是让剧本、分镜、数据库三者的字段能对上，避免各写各的。

## 剧本在流程里的位置

```
剧本 script ──→ 场 scene ──→ 镜头 shot ──→ 生成任务 generation
   (文本)        (结构化)      (分镜表)         (API 调用)
```

**剧本是分镜的上游。** 先有剧本，再有场，最后才拆成分镜。
这个顺序不能颠倒——直接从想法跳分镜，改稿时会全军覆没。

## 为什么剧本要单独存，不能只写在分镜里

`shot.dialogue` 只有台词，没有动作、没有场景、没有节奏。而**改稿是常态**：

- 剧本改一句台词，可能牵动 3 个镜头
- 如果剧本只存在 Word 里，没人知道当前分镜对应的是第几版剧本
- `script` 表用 `version` + `is_current` 解决这个问题：

```sql
-- 第 1 集的现行稿
SELECT * FROM script WHERE episode_id = 1 AND is_current = 1;

-- 出新版：旧稿降级，新稿上线
UPDATE script SET is_current = 0 WHERE episode_id = 1;
INSERT INTO script (episode_id, version, content, is_current)
VALUES (1, 2, '...', 1);
```

**旧版永远不删。** 半年后回看"这个镜头当时为什么这么拍"，答案在那版剧本里。

## 场（scene）的字段

| 字段 | 写法 | 例 |
|---|---|---|
| `seq` | 场号，从 1 开始 | `3` |
| `slug` | 场景标题 | `内景 · 夜 · 客厅` |
| `location` | 地点 | `女主家客厅` |
| `time_of_day` | 日/夜/晨/昏 | `夜` |
| `action` | 动作描述 | `她把照片扣在桌上，手在抖` |
| `dialogue` | 对白 | `你到底是谁？` |
| `beat` | 节奏位置 | `钩子`/`建立`/`升级`/`高潮`/`扣子` |
| `duration_s` | 预估时长 | `14` |

`beat` 字段是为了对齐 `竖屏短剧结构模板.md` 的节奏表，让"这一场在整体结构里干什么活"变成可查的数据，
而不是靠脑子记。

## 对白的三条纪律

1. **一句不超过 12 个字。** 80 秒塞不下长台词；超了必然拖垮节奏，配音时也会被压缩到听不清。
2. **能演就别说的，不要写。** 模型生成的是画面。`她红了眼眶` 比 `她说我心里很难受` 有效得多，
   而且后者会让模型不知道该生成什么表情。
3. **对白必须可执行。** 写完问一句："这句话对应的画面动作是什么？"
   如果答不上来，模型也答不上来。

## 场的拆解粒度

**判断标准：一场 = 一个连续的时空。** 换地点、换时间、换人物组合，就换一场。

一场通常拆成 3–6 个镜头。如果一场拆出 10 个以上镜头，说明这场太大了，应该再切。
反过来，一场只拆出 1 个镜头，说明它可能该并进相邻的场。

## 与数据库的操作

```sql
-- 建剧本
INSERT INTO script (episode_id, version, title, logline, content)
VALUES (1, 1, '第1集', '一句话梗概', '（完整剧本 markdown）');

-- 建场
INSERT INTO scene (script_id, seq, slug, location, time_of_day, action, dialogue, beat, duration_s)
VALUES (1, 1, '内景 · 夜 · 客厅', '女主家', '夜', '她把照片扣在桌上', '你到底是谁？', '钩子', 14);

-- 把镜头挂到场（v2 新增的 shot.scene_id）
UPDATE shot SET scene_id = 1 WHERE episode_id = 1 AND seq BETWEEN 1 AND 4;

-- 看剧本→场→镜头 的覆盖情况
SELECT * FROM v_episode_outline WHERE episode_seq = 1;
```

`v_episode_outline` 会告诉你：现行剧本是第几版、拆了几场、场的预估总时长、有多少个镜头、
镜头的总时长。**`planned_seconds` 和 `shot_seconds` 差太多，说明剧本和分镜已经脱节了**——
这是改稿后最容易出的问题，用这个视图一眼能看出来。
