## 一、⚠️ 一个必须解决的来源冲突：要不要负面提示词

| 来源 | 主张 |
|---|---|
| **Higgs Field · Lira**（面向 Soul/NBP/GPT Image 2） | **"这里没有任何模型带有反向提示词参数。"** 不需要的元素要**正向描述你想要的**来消除。"不要 XX"堆砌反而会把概念注入画面 |
| **AI漫剧分镜提示词全体系资料手册**（面向 SD/MJ/即梦） | **"精准指令 = 正向描述 + 反向约束"**，并给了分类负面词清单（人像类必加：畸形肢体、多手指、错位眼睛、僵硬表情、模糊面部） |
| **OpenMontage**（面向 Seedance） | 约束写在**具名正向锁定块**里（SCREEN DIRECTION / COUNT LOCK / STILLNESS LOCK） |

**三者其实说的是同一件事的两面**：**平台有没有独立的负面提示词参数**。

- **Midjourney** 有 `--no`；**SD** 有 negative prompt 输入框 → **该写**
- **Soul 2.0 / NBP / GPT Image 2** 没有这个参数 → **写了也没用，反而污染**
- **火山方舟的 Seedream / Seedance** → **我方尚未验证**

**这是一条待实测项。** 我方现状：`shot.negative_prompt` 字段存在，
但图像调用（`stage_refs.py`）的请求体只发
`model / prompt / response_format / size / watermark`——**没发负面词**。
视频调用是否发、以及 Ark 是否接受，需要确认。

**建议**：做一次最小实测——同一提示词分别带/不带负面词各出一张，
看模型行为是否变化。在验证之前，**主力用正向锁定，负面词只用于阻止已知失败模式**
（这与 Lira 和 OpenMontage 一致，也是风险最低的默认）。

## 二、16 个运镜提示词模板（可直接进第 5/6 阶段）

**提示词四要素**：`运镜类型 + 核心参数 + 场景适配 + 风格要求`

**核心参数**：运镜速度（慢推/快推、缓移/急移）、镜头焦距（广角/长焦/标准）、
取景范围（全景/中景/近景/特写）、焦点控制（跟焦/定焦）、画面效果（稳定/抖动/模糊渐变）

**示例格式**（对照我方现状——我们的 `camera_move` 字段太粗）：
```
【慢推 + 标准焦距 + 近景 + 跟焦主角面部 + 稳定画面 + 日系动漫风格】
```
> 而非单一的"推镜头拍主角"。

### 基础运镜（叙事核心，适合对话/过渡/介绍）

| 运镜 | 变体 | 提示词模板要点 |
|---|---|---|
| **推镜** Push In | 慢推 / 快推 / 渐进式 | 「慢推镜头，标准焦距，近景，跟焦主角面部，稳定画面…背景轻微虚化」 |
| **拉镜** Pull Back | 缓拉 / 快拉 / 定点 | 「缓拉拉镜，广角焦距，从主角特写逐步拉至全景，展现荒芜废墟…冷色调」 |
| **移镜** Tracking | 水平 / 弧形 / 斜向 | 「水平缓移镜头，跟焦奔跑的主角，背景动态模糊，突出速度感」 |
| **摇镜** Pan | 左右 / 上下 / 环形 | 「上下快摇镜头，跟随主角的挥剑动作，从剑尖摇至主角面部」 |
| **定镜** Static | 近景 / 全景 / 特写 | 「定镜，长焦焦距，特写，拍摄主角颤抖的手，细节清晰」 |

### 进阶运镜（强化视觉冲击）

| 运镜 | 变体 | 要点 |
|---|---|---|
| **跟镜** Follow | 第一视角 / 第三人称 / 低空 | 「低空跟镜，广角焦距，跟随主角在丛林中奔跑，**镜头贴近地面**，展现草丛的动态」 |
| **升/降镜** Crane | 缓慢升 / 急升 / 降 | 升镜=主角觉醒/英雄登场/宏大建筑；降镜=找地面线索/陷入困境/压抑密室 |
| **旋转镜** Spin | 缓慢 / 快速 / 螺旋 | 「螺旋旋转镜，从主角头部向下方螺旋旋转，聚焦地面的倒影，营造意识模糊」 |
| **变焦镜** Zoom | 入 / 出 / 反复 | **与推拉镜的区别：变焦不改变镜头位置，只改视野范围** |
| **手持镜** Handheld | 轻微 / 剧烈 / **呼吸感** | 「呼吸感手持抖动，长焦焦距，拍摄主角躲藏时的视角，画面随呼吸轻微起伏」 |

### 特殊运镜（创意表达）

**慢动作**（3 倍 / 5 倍 / 渐变）、**闪回**（模糊渐变 / 旋转叠化 / 变焦）、
**分屏**（二分 / 三分 / 叠加）、**鱼眼**、**主观镜头 POV**（侦查 / 战斗 / 梦境）

### ⭐ 场景与情绪的对应关系（可直接做校验）

| 场景情绪 | 该用 | 不该用 |
|---|---|---|
| 紧张的追逐戏 | 快推、急移、手持镜 | — |
| 治愈的日常戏 | 慢推、缓移、定镜 | — |
| 宏大的场景 | 升镜、拉镜、广角摇镜 | — |
| 悲伤的情绪 | 慢动作、缓拉、定镜特写 | — |
| **日常对话** | — | **快速旋转镜**（会导致画面混乱、破坏叙事节奏） |

## 三、分镜提示词全体系（第 5/6 阶段参考）

### 核心公式

```
基础：[核心主体(权重1.5-1.7)] + [动作/状态] + [场景环境] + [风格定义] + [镜头语言] + [画质要求]
完整：[核心主体(权重)] + [细节特征] + [动作/状态] + [场景环境] + [风格定义]
      + [镜头语言] + [光影效果] + [画质要求] | 负面提示词
```

**权重分配原则**：`核心主体 > 细节特征 > 场景环境`，避免 AI 喧宾夺主。
用 `角色名:1.6` 标注，核心元素 1.5–1.7，次要 1.2–1.4。

> ⚠️ **这套权重语法是 SD/MJ 系的**（`(word:1.6)`）。**Seedance/Seedream 用的是
> `【@素材X】` 句柄，不是权重数字。** 概念（"什么最重要"）可借用，语法不能照搬。

### 5 种模板

| 模板 | 用途 |
|---|---|
| **快速构思（极简）** | `[风格]+[景别]:[主体][动作]，[核心细节]` |
| **精准出图（完整）** | 上面那个完整公式 |
| **多格分镜** | `[类型]:[N]格 1格:[描述][镜头语言+光影] … \| 统一负面词` |
| **动态分镜** | `[静态描述] + [动态指令] + [台词/音效] + [转场效果]` |
| **系列连贯** | `[固定前缀：角色特征+基础风格] + [单集描述] + [参考指令] + [画质]` |

**系列连贯的固定前缀示例**（正是我们要的"跨集一致性"）：
> 「一个名叫莉莉的女孩，留着黑色短发，扎着红色发夹，穿着蓝色校服…（统一角色特征）」

### 景别与用途对照

| 景别 | 核心用途 |
|---|---|
| 远景 | 展示环境全貌，奠定氛围 |
| 全景 | 人物全身 + 环境，展现动作全貌 |
| 中景 | 腰部以上，适合对话/日常动作 |
| 近景 | 胸部以上，突出表情互动 |
| 特写 | 细节聚焦（脸/手/物），强化情绪 |

### 角色一致性要素（系列漫剧核心）

- **核心特征固定**：发型 + 五官 + 着装 + 体型
  （`short black hair, round face, blue school uniform, slim figure`）
- **参考指令**：加「参考上一张图的角色造型、色调和风格」或 `same character as previous`
- **角色卡调用**：`reference image: (角色卡URL)`

### 避坑指南

| 问题 | 解法 |
|---|---|
| 出图模糊 | 正向加"高锐度、清晰边缘"；负面加"blurry、模糊边缘" |
| 角色表情僵硬 | 补"自然微笑、眼神灵动、natural expression" |
| 风格混乱 | 固定风格关键词，加"统一风格，consistent style" |
| **动作不连贯** | **拆分分镜**（"环顾四周+抓取手机"拆成两个镜头），加"动作连贯" |

## 四、角色一致性全流程控制指南

**核心结论**：从**五维框架**（外貌、服饰、动作、情绪、镜头语言）入手，
结合**五大手段**（角色档案、参考图锁定、专用工具、参数固化、后期校准），
构建"设定 → 生成 → 审查"的闭环。

### ⚠️ 与《拾音人》的表面冲突（其实互补）

| 来源 | 说法 |
|---|---|
| **本指南** | 建立角色 **360 度视图参考库**（正面、侧面、45 度角、背面） |
| **《拾音人》规范** | **禁止三视图/多视图作为参考素材**——官方明确引发双胞胎 |

**语境不同，不矛盾**：
- 360 度视图库是**给人看的资产**（审阅、后期修图参考、团队协作）
- 《拾音人》禁的是**把多视图当参考素材传给模型**

**所以可以两者都做**：建库供人用，但**喂给模型时只给「大头照 + 全身照」两张**。

### 角色 DNA 档案（可量化的描述）

| 维度 | 清单 | 技巧 |
|---|---|---|
| 面部 | 脸型、眼距、鼻梁高度、嘴唇厚度、眉形 | 精确词汇 + 结构锁定词 |
| 发型 | 发色、长度、纹理、**分缝位置** | 加强制指令"始终保持发型不变" |
| 体型 | 身高、肩宽、腰围、四肢比例 | **量化**："身高 175cm，肩宽 42cm，九头身比例" |
| 服饰 | 主色调、款式、材质、标志性配件 | 固定描述句式，**只改场景相关词** |
| 性格/表情 | 常用表情、眼神特点、肢体习惯 | "符合 XX 性格的表情" |

**实操模板**：
> 角色名：林墨
> 核心特征：18 岁少年，鹅蛋脸，剑眉星目，**左眼下方有一颗泪痣**，
> 黑色碎发，高 180cm，偏瘦体型，常穿黑色连帽卫衣配银色项链，
> 眼神清冷，嘴角习惯性微扬。

**这与《拾音人》的"可测量硬指标 + 独特标识锚点"是同一条原则。**

### 参数固化三原则

1. **固定模型版本**：全程同一模型，避免风格撕裂
2. **锁定核心参数**：采样器固定、步数 ≥30（推荐 40–50）、CFG 7–8、**记录满意结果的 seed 复用**
3. **统一提示词结构**：`[角色核心特征] + [当前场景/动作/表情] + [风格词] + [一致性锁定词]`

### 一致性检查清单（可直接做校验器）

- **面部**：五官位置、痣/疤痕等标记、眼神方向
- **发型**：长度、分缝、纹理、颜色
- **服饰**：款式、颜色、配件位置、**褶皱方向**
- **体型**：比例、身高、肩宽、腰围
- **风格**：线条粗细、上色方式、阴影风格

### 团队协作三件套（值得我们借鉴）

1. 建立**角色风格指南文档**，包含所有特征描述和参考图
2. **用版本控制工具（如 Git）管理提示词和模型文件** ← 我们已经在做
3. **设立"一致性审查员"角色**，专门负责跨章节核对 ← 我们的 `consistency-guard` 技能正是这个

### 常见问题与解法

| 问题 | 原因 | 解法 |
|---|---|---|
| 角色脸崩 | 特征描述模糊 / 模型不稳定 | 补详细面部特征；锁定面部；**降低重绘强度** |
| 服饰变化 | 提示词中服饰描述不一致 | 固定服饰描述句式；加"保持服装不变"强制指令 |
| 比例失调 | 模型对人体理解不足 | 启用姿态检测；**加详细的体型量化描述** |
| 风格漂移 | 混用了不同模型/LoRA | 固定单一模型；控制 LoRA 权重 0.6–0.8 |

## 五、可以直接进我们流程的改动

| 我们的现状 | 应该改成 | 依据 |
|---|---|---|
| `camera_move` 只有一个词（"推"/"摇"） | **拆成 5 个参数**：速度 + 焦距 + 景别 + 焦点控制 + 画面效果 | 运镜模板四要素 |
| 运镜没有场景匹配校验 | 加**情绪→运镜**对照校验；**日常对话禁用快速旋转镜** | 运镜指南 §5.1 |
| 单镜只有一种运镜 | 可考虑"**变焦 vs 推拉**"的区分（变焦不改机位、只改视野） | 运镜指南 §3.4 |
| 没有"呼吸感手持"这个概念 | 加入（躲藏/紧张场景很有用） | 运镜模板 |
| `negative_prompt` 立场未定 | **先实测 Ark 是否吃负面词**；在此之前正向锁定为主 | 见 §1 冲突 |
| 情绪标注只写情绪 | 改成 **目标 + 障碍 + 策略**（Higgs Field ACTING） | 外部技能精华 §2 |
| 没有一致性检查清单 | 把**面部/发型/服饰/体型/风格**五查做成校验器 | 本文 §4 |
| 没有"角色风格指南文档"概念 | DB 里已有 entity/description，可导出成给人看的指南 | 本文 §4 |
| 场景描述不固定句式 | **固定服饰/场景描述句式，只改场景相关词** | 本文 §4 |
| 提示词里可能混入权重语法 | **不用 SD 权重语法**，改用 `【@素材X】` 句柄 | 平台差异 |
