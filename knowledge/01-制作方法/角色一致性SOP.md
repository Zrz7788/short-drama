# 角色一致性 SOP

> 仿真人短剧的**第一号失败模式**：主角跨镜头、跨集崩脸。这个问题的代价极高——
> 拍完 20 个镜头才发现主角变成三个人，等于全部重抽。
>
> 本页是工作方法，属于**待验证假设**；跑完真实项目后请把结果回流到 `04-复盘/`。

## 三条铁律

### 1. 先定妆，再拍片

**不要用纯文生视频硬编角色。** 顺序必须是：

1. 用 Seedream 生成角色定妆图（正面/侧面/半身/全身），反复抽到满意为止
2. 把选定的图存进 `assets/refs/`，路径写进 `character.ref_image_path`
3. 记录生成该图用的 prompt 与 `seed`，写进 `character.seed`
4. **之后所有镜头都用图生视频**，把定妆图作为 `reference_image` 传入

### 2. seed 与参考图一起固定

`character.seed` 是固化随机性的锚点。每次生成都要：
- 传 `reference_image`（定妆图）
- 记录本次实际用的 `seed` 到 `generation.seed`

**只传参考图不固定 seed，仍然会漂。** 两者要一起用。

### 3. 外貌设定写成可粘贴的一段话

`character.appearance` 不是给人看的备注，是**每次都要拼进 prompt 的文本块**。所以要写成
可直接粘贴的形式，而不是散文。

好的写法：

```
35岁女性，东亚面孔，齐肩黑色直发，杏眼，左眉尾有浅疤，戴细金边眼镜，
常穿深灰高领针织衫。皮肤偏冷调，自然光下呈中性色温。
```

坏的写法：`成熟知性的女性`（模型无法执行）

## 出片时的固定结构

每个角色镜头的 prompt 建议按这个顺序拼：

```
[景别] + [角色外貌块] + [本镜动作/表情] + [环境与光线] + [运镜] + [风格]
```

外貌块直接来自 `character.appearance`，**逐字复制，不要临场改写**——改写就是漂移的开始。

## 高风险场景（重点抽卡对象）

| 场景 | 风险 | 对策 |
|---|---|---|
| 正脸特写 | 五官细节全暴露，差异最明显 | Draft 多抽，4–6 次 |
| 两人同框 | 可能出现"融合脸" | 参考图分别传，必要时拆成单人镜头 |
| 侧脸转正脸 | 中途换角度容易换人 | 加长单镜时长，或拆成两个镜头 |
| 快速运动 | 面部模糊，反而容错高 | 可以少抽 |
| 背影/远景/手部 | 不露脸 | 直出即可，不必浪费预算 |

## 跨集一致性

`character` 表挂在 `project` 下，不是挂在 `episode` 下——**刻意如此**。
角色设定是全剧级的资产，第 1 集定稿后，第 2–100 集全部复用同一份 `character` 记录。

**换角色设定属于重大变更**，应当在 `04-复盘/` 记录变更原因与影响的镜头范围。

## 数据库怎么承接

```
character (ref_image_path, seed, appearance)
    ↑ char_id
  shot ──→ generation (seed, task_id, status, cost)
```

- `shot.char_id` 保证每个镜头都知道自己归谁
- `generation.seed` 保证每次出片都可追溯、可复现
- 用 `v_shot_progress` 视图能一眼看出哪些镜头还没通过

## 待验证清单

跑完第一集后，回头回答这几个问题并写进 `04-复盘/`：

1. 用参考图 + 固定 seed，同角色跨镜头的实际崩脸率是多少？
2. 哪些镜头类型崩得最多？（验证上面的"高风险场景"表）
3. 一个角色平均要几张定妆图才够用？
4. 参考图给 1 张和多张，效果差异有多大？
