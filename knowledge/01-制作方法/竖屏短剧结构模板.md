# 竖屏短剧结构模板

> ⚠️ **这是一份起始模板，不是经过验证的结论。** 节奏、钩子位置、集尾扣子这些属于"平台手感"，
> 必须用你的实际数据和观众反馈来校准。跑完真实项目后请把修正写回本页，或记进 `04-复盘/`。

## 基本参数

| 参数 | 值 | 来源 |
|---|---|---|
| 画幅 | 9:16 竖屏 | 竖屏短剧通例 |
| 单集时长 | 约 80 秒 | 本项目设定 |
| 平均单镜时长 | 4 秒 | 对应 Seedance 2.x 的 4 秒起算 |
| 单集镜头数 | 约 20 个 | 80 ÷ 4 |
| 整部剧集数 | 60–100 集 | 竖屏短剧常见体量 |

**为什么是 4 秒**：Seedance 2.x 的 `duration` 支持 4–15 秒，4 秒是最小计费单位。
镜头平均 4 秒意味着不浪费；如果写成 5 秒再用 4 秒的素材，等于每镜白掏 20%。

## 80 秒节奏模板（待校准）

| 时间轴 | 段落 | 作用 |
|---|---|---|
| 0–3 秒 | **钩子** | 最强冲突/最反常画面。决定完播率，不能有任何铺垫 |
| 3–15 秒 | 情境建立 | 谁、在哪、和谁对立。信息密度要高 |
| 15–55 秒 | 冲突升级 | 主体段落，2–3 个转折 |
| 55–72 秒 | 高潮/反转 | 情绪峰值 |
| 72–80 秒 | **扣子** | 悬念断点，逼观众看下一集 |

**假设**（需要你的数据验证）：
- 前 3 秒决定一半的流失
- 集尾扣子决定追更率，比单集质量更重要

## 分镜数分配建议

按上面的节奏，20 个镜头大致这样分：

| 段落 | 镜头数 | 备注 |
|---|---|---|
| 钩子 | 1 | 必须是强画面，值得多抽卡 |
| 情境建立 | 3–4 | |
| 冲突升级 | 8–10 | 主体 |
| 高潮/反转 | 3–4 | 含正脸特写，重点抽卡对象 |
| 扣子 | 1–2 | |

## 写法纪律

1. **钩子镜头单独拿出来先做**。它是全集最重要的一镜，别留到最后预算耗尽时才发现抽不出来。
2. **对白要短**。80 秒塞不下长台词；一句超过 12 字就会拖垮节奏。
3. **每个转折都要有可见的动作或表情变化**，不能只靠台词交代——模型生成的是画面，不是信息。
4. **集尾扣子必须是"新信息"**，不能只是"事情没说完"。观众能分辨这两个。

## 与数据库的对应
