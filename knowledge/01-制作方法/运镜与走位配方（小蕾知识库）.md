## 二、运镜 → 提示词（**原文照录**）

| 运镜 | 它的提示词 |
|---|---|
| 跟镜头 | 智能跟随，速度自适应主体运动（步行/奔跑），平滑跟拍，轻微镜头晃动模拟手持感，保持主体清晰追踪 |
| 推镜头 | 平滑推进，动态对焦系统，从全景渐变至中景，每秒移动 5-10 厘米，镜头轻微呼吸感增强沉浸 |
| 拉镜头 | 智能拉远，0.3 秒内完成从特写至全景，加入轻微镜头模糊与透视变化，增强空间感 |
| 水平摇镜头 | 动态水平摇镜，加入轻微速度曲线（缓入缓出），扫视过程中自动对焦环境细节 |
| 垂直摇镜头 | 快速垂直摇镜，加入动态模糊与光影追踪，1.5 秒内完成，强化视觉冲击与情绪张力 |
| 移镜头 | 智能侧移，镜头保持与主体距离自适应，加入轻微上下浮动模拟步行感 |
| 升镜头 | 智能垂直上升，速度曲线设计（缓起缓停），上升过程中自动调整曝光与焦距，背景环境渐变式扩展 |
| 降镜头 | 快速垂直降落，加入轻微镜头震动与风噪模拟，最终缓慢停稳，背景虚化渐变 |
| 旋转镜头 | 智能旋转运镜，速度可调（慢速 360° 或快速急旋），旋转过程中保持主体在画面中央 |
| 环绕镜头 | 智能环绕跟踪，保持与主体恒定距离，环绕速度可调（慢速 30°/秒或快速 90°/秒），始终正对主体 |

> 另有「运镜 + 物体运动」组合表（垂直俯冲+投掷、升镜头+物体远离…），
> 场景是**动作/战争/CG 投掷**，与我们写实题材无关，未转录。
> 值得一提的是它给运动的**量化参数**（"从 8 米高空 45° 斜俯拍下降到 3 米"、
> "2m/s"、"0.5 秒黑场"）——**这个思路我们可以用**：速度/距离写数字，别写"缓慢地"。

## 三、我们**采纳**了什么（已进代码）

落在 `pipeline/prompt_recipes.py`，由 `stage_prompts.py` 注入提示词：

| 采纳 | 怎么改的 | 为什么改 |
|---|---|---|
| **景别配方句** | 加到提示词新的一行 `【景别配方】`，如特写→"超清微距特写，皮肤纹理与物体质感增强" | 我们原来只写一个词（"特写"），模型不知道往哪使劲 |
| **运镜配方句** | 只在字段是**表内短标签**（推/跟/移/环绕，或"推镜头"式别名）时补 | 分镜已写"陪伴式平移""爆发式急推"这类富描述的**不补**，免得写两遍 |
| **运动量化** | 沿用我们自己的 `movement_speed`（已带数字） | 它的组合表证明了"写数字比写形容词稳" |

### 改了它的两处（**实测踩出来的**，不是嫌它写得不好）

1. **剥掉"运动"再注入景别**
   它写全景是"**智能全景跟随**…"、特写要"加入**轻微镜头颤动**"。
   但运动归我们自己的【运镜】和**静止锁**管——照抄进去会和"固定机位"**互相打架**
   （S06/S07/S11 就是固定镜）。
2. **剥掉"从哪到哪"和速度数字再注入运镜**
   ⚠️ 实测：它写推镜头是"…**从全景渐变至中景**…"，套到 S05
   （分镜写的是"**爆发式急推**至眼部特写"）上，就变成
   **一个快推到眼睛的镜头，提示词里却写着"由全景渐入中景"**——自相矛盾。
   所以配方句只留**技法性格**，范围和速度交给分镜字段自己说。

## 四、我们**没采纳**的两条（留档，别以为是漏了）

| 它这么做 | 我们为什么暂时不用 |
|---|---|
| 大量用 **"0-3 秒 / 3-5 秒 / 5-8 秒"精确时间码**推进动作 | 与我们《拾音人范本与工艺规范》§一.2 **直接冲突**（该文说"模型对精确时间支持不稳定，不写时间码，用镜头序号+事件顺序"）。**两条不能都信，尚未实测**——所以配方里一律不带时间码。**要验：出一镜对比 ≈¥7.5** |
| **3D CG 国漫 / 史诗奇幻**的材质与特效写法（PBR 物理材质、全局体积光照、8K 超清、剑气/火焰特效） | 我们是**写实仿真人**题材，这些词会把画面往 CG 拽 |

## 五、另一个**有独立价值**的东西：用参考图上的轨迹线控制走位

它用**第二张参考图**画运动图，然后在提示词里声明（原文）：

> 图片 1 为拍摄场景，图片 2 为人物走位。其中**蓝色点代表男主初始位置，蓝色带箭头的线表示男主运动方向**；
> **红色点代表女主初始位置，红色带箭头的线表示女主运动方向**；**两人最终在绿色点处相遇**。
> **请注意，视频生成的时候请不要出现蓝色、红色、绿色的点，也不要出现箭头。**

同一手法还用于：**控制镜头运动**（蓝线=相机轨迹）、**展示场景建筑**（沿轨迹线穿行）、
**第一视角**（第一人称视线方向）。

**为什么这条对我们特别值**：我们反复栽在**站位/走位/调度**上——
S12 双人裁切把人裁没、人物入场关系交代不清（那份教程也点出"人物入场用全景交代场景与人物关系"）。
而画一张轨迹图**用 PIL 就能做，零成本**。
