# 知识库

仿真人短剧项目的**方法与依据**沉淀。三条线的分工：

| 载体 | 面向谁 | 装什么 | 位置 |
|---|---|---|---|
| **知识库**（本目录） | 人 | 方法、SOP、价格依据、成本模型 | `knowledge/` |
| **Skill** | 智能体 | 同样的知识，压缩成可自动加载的指令 | `.dsh/skills/` |
| **数据库** | 程序 | 生产数据：项目、集、镜头、素材、任务、成本 | `data/drama.db` |

知识库改了，对应的 skill 也要跟着改——**两处不同步就会出问题**。数据库的 schema 定义在 `db/schema.sql`，是字段口径的唯一真源。

## 两条纪律

1. **价格与模型 ID 必须标置信度和来源。** 网上关于火山方舟计费的 AI 生成内容大量互相矛盾（同一页出现 10 秒视频消耗 2200 与 5000 tokens 两种说法），无出处的数字不写进 `02`。
2. **`01` 里的方法在拿到真实数据前都是假设。** 抽卡命中率、单镜可用率这类数字，只有跑过才知道，跑完回流到 `04-复盘/`，再回头修 `01`。
