# 项目档案

每部剧一个文件，命名 `剧名.md`。从下面的模板复制。

建档后同步在数据库里建 `project` 记录：

```sql
INSERT INTO project (name, logline, genre, target_episode_seconds)
VALUES ('剧名', '一句话故事', '悬疑', 80);
```

## 一条纪律

**角色技术设定只在数据库里维护。** 本目录的文件写创作意图和设定背景，
`ref_image_path`、`seed`、`voice_id` 这些一旦两处都写就会漂移，最后没人知道哪个是对的。
