# 单集成本模型

> 单价出处见 `火山方舟模型与价格.md`。$1 ≈ ¥7（仅用于把美元标价折成人民币）。

## 模型假设

| 参数 | 取值 |
|---|---|
| 单集时长 | 80 秒 |
| 平均单镜时长 | 4 秒 |
| 镜头数 | 20 |
| 每镜抽卡 | 3 次（常规） |
| 分辨率 | 1080p |

## 单集账（2.5 + Draft，抽卡 3 次）

| 项目 | 金额 | 占比 |
|---|---|---|
| 视频生成 | ¥178.4 | 91% |
| 图片（50 张 × ¥0.2 估） | ¥10.0 | 5% |
| 配音 | **¥0** | 0% |
| 我的 token（agent 成本） | ¥8.0 | 4% |
| **合计** | **≈ ¥196** | 100% |

计算过程：
- 样片：20 镜 × 3 次 × 4 秒 × ¥0.26 = ¥62.4
- 成片：20 镜 × 4 秒 × ¥1.45 = ¥116.0
- 视频小计 = ¥178.4

**配音为什么是 0**：Seedance 2.x 原生支持音频生成与唇形同步，不需要另买 TTS 或口型服务。
若改用外部 TTS + `reference_audio`，把成本填进 `cost_ledger`。

## 整部剧

| 集数 | 单集 ¥196 | 单集 ¥300（高抽卡） |
|---|---|---|
| 60 集 | ¥11,760 | ¥18,000 |
| 80 集 | **¥15,680** | ¥24,000 |
| 100 集 | ¥19,600 | ¥30,000 |

**单集不贵，整部剧才吓人。** 预算讨论必须落到集数上，"80 秒要多少钱"这个问题本身缺一个变量。

## 一个必须记住的比例

**视频抽卡占 91%，agent 的 token 成本只占 4%。**

推论：在"换哪个大模型"上纠结是优化错了地方。一次多余的抽卡（4 秒 ≈ ¥5.8）就能吃掉
换成便宜模型省下的全部差价。**把精力放在压低抽卡次数和提高分镜质量上。**

## 三档情景

| 情景 | 配置 | 单集视频成本 |
|---|---|---|
| 省钱 | 2.0 pro 直抽，抽卡 2 次，非关键镜头 720p | ≈ ¥160 |
| 常规 | 2.5 + Draft，抽卡 3 次，1080p | ≈ ¥178 |
| 精品 | 2.5 + Draft，抽卡 5 次，难镜头单独加抽 | ≈ ¥220 |

（上表是视频部分；整集再加约 ¥18 的图片与 token。）

## 数据库怎么用

- `price_book`：价目表，改价只改这里
- `cost_ledger`：实际流水，按 `episode_id` 汇总
- `generation.cost`：每次调用的实际花费
- `v_episode_cost`：按集汇总的视图

```sql
-- 看某一集的实际花费
SELECT * FROM v_episode_cost WHERE episode_seq = 1;

-- 看实际抽卡次数是否超出计划（复盘用）
SELECT shot_seq, draws_planned, attempts, cost
FROM v_shot_progress WHERE episode_seq = 1 AND attempts > draws_planned;
```

## 尚未计入的项目

诚实列出这个模型**没有**包含的成本：

- **返工**：分镜改稿导致已生成的镜头作废（如果改稿频繁，这笔可能很大）
- **失败重试**：API 报错、任务 expired 的重复调用
- **剪辑人力**：拼接、字幕、调色的时间成本
- **ffmpeg 等工具链**：本机尚未安装，需补
- **BGM/音效素材**：若不用原生音频生成，需另购授权

跑完真实项目后，用 `04-复盘/` 把实际值回填，替换这里的假设。

## ⭐ 预算吃紧时的价值排序（依《6、女频氛围感》）

**优先砸光影与画面层次，而不是无限追求场景精确度。**

原话的价值排序（竖屏短剧）：**光影与画面层次 > 场景精确度 > 道具细节**。
理由：观众对"氛围对不对"极敏感，对"这个柜子是不是那个牌子"几乎无感；
而光影一旦不对，**每一镜都要返工**。

**本项目据此的成本纪律**：
- 出图阶段：**人物（脸与妆造）** 与 **场景的光影基调** 不可省；
  道具按 `main/secondary` 分级出，`background` 级不出图（只在连续性记录里留名）。
- 视频阶段：先出 **Draft 档**验证动作与运镜，确认后才出正式档。
- 宁可少做几个场景，也不要让光影不统一。
