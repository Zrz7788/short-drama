# 火山方舟（Ark）模型与价格

> 单价以**火山方舟控制台模型详情页**为准。本页只记录核实过的数字，并标注置信度与出处。

## 端点与认证

- 国内站 base URL：`https://ark.cn-beijing.volces.com/api/v3`
- 鉴权头：`Authorization: Bearer $ARK_API_KEY`
- 密钥从环境变量读，**不写进任何进 git 的文件**（`.gitignore` 已挡 `.env`）

### 本机环境约束

本机（Windows + DSH 沙箱）下**不要用 `curl.exe` 或 PowerShell 的 `Invoke-WebRequest` 调 API**：
两者走 Windows schannel，会因凭证不可用报 `SEC_E_NO_CREDENTIALS`，TLS 握手直接失败。

**改用 Python `urllib` / `requests` 或 Node `fetch`**——走 OpenSSL，实测可正常访问 Ark。

### 原生音频与唇形同步

Seedance 2.x 原生支持音频生成与唇形同步（`generate_audio` 默认 `true`），对白、音效、环境音可一步出，
**不需要另配第三方口型服务**。也可传 `reference_audio` 用自有配音驱动口型。

### 图片接口（同步，无任务轮询）

与视频不同，**图片生成是同步接口**，一次请求直接拿结果：

```
POST /api/v3/images/generations
```

请求体：

```json
{
  "model": "doubao-seedream-5-0-pro-260628",
  "prompt": "...",
  "response_format": "url",
  "size": "2K",
  "watermark": false,
  "image": ["data:image/png;base64,..."]
}
```

- `size`：档位 `1K`/`2K`/`4K`，或显式 `宽x高`。
  合法域实测为**总像素 ≥ 2560×1440 且 ≤ 4096×4096**，宽高比 [1/16, 16]；
  低于下限等比放大，超上界等比缩小
- `image`：**图生图的参考图，是一个 data URL 数组**（不是 URL 字符串）。
  官方支持最多 14 张参考图
- `response_format` 固定 `url`；`watermark: false` 关掉右下角水印

响应：

```json
{
  "model": "...",
  "data": [{"url": "https://..."}]
}
```

两个要注意的点：

1. **响应不保证回传 `model`**，取不到时应回落到请求里用的模型，否则历史记录无法追溯
2. `data[]` 里可能是 `b64_json` 而不是 `url`，两种都要处理

Seedream 5.0 pro 在同一端点上还支持**指令编辑**（基准图 + 编辑指令）。
方舟没有掩码局部重绘能力，`mask` 类需求只能走整图重绘。

### 错误码含义

| 现象 | 含义 | 处理 |
|---|---|---|
| 401 / `AuthenticationError` | 密钥无效，或**未开通该模型权限** | 查 key 与控制台权限 |
| 429 / `ModelAccountIpmRateLimitExceeded` | 限流 | 退避重试（实测 25s × 2 有效） |
| 400 / `InvalidParameter` | 参数非法（size 越界等） | 检查请求体 |

`fast` / `mini` 传 1080p 或 4k 会返回 **400**——这是视频模型的硬约束，见上表。

### 视频生成流程（异步任务）

1. `POST /api/v3/contents/generations/tasks` 创建任务，拿回任务 ID
2. `GET /api/v3/contents/generations/tasks/{id}` 轮询，间隔 5–10 秒
3. 状态机：`queued → running → succeeded / failed / cancelled / expired`
4. 成功后取 `content.video_url` **立即下载**，URL 会过期
5. 5 秒 1080P 通常耗时 60–150 秒，轮询超时建议 300 秒以上

```json
{
  "model": "doubao-seedance-2-5-260628",
  "content": [
    {"type": "text", "text": "竖屏近景，女主角回头，电影感自然光"},
    {"type": "image_url", "image_url": {"url": "https://.../ref.png"}, "role": "reference_image"}
  ],
  "ratio": "9:16",
  "duration": 4,
  "resolution": "1080p",
  "draft": true,
  "generate_audio": true,
  "watermark": false
}
```

## 为什么 Draft 单价是"反推"而不是查到的

火山引擎 2026-09-22 上线 Seedance 2.5 的 Draft（样片）模式，官方口径：

- 5 秒 1080P 镜头、不含输入视频、**抽卡 4 次命中 → 省 57%**
- **抽卡 20 抽 1 → 省 77%**

官方没公布 480P 样片的单价。把已知的 ¥1.45/秒 代入这两个数据点反解：

| 抽卡 | 不用 Draft | 用 Draft | 解出的样片单价 |
|---|---|---|---|
| 4 次 | 4×5×1.45 = ¥29 | 4×5×d + 5×1.45 | 官方省 57% → **d = ¥0.26** |
| 20 次 | 20×5×1.45 = ¥145 | 20×5×d + 5×1.45 | 官方省 77% → **d = ¥0.26** |

两个独立数据点解出同一个值，因此取 **¥0.26/秒**（约 1080P 的 1/5.6）。

⚠️ **前提**：这成立的前提是 ¥1.45 是 **1080P** 的单价。如果它其实是 2.5 不分分辨率的统一价，
反推值要重算。**核一下控制台里 480P 和 1080P 是否同价即可确认。**

## 不要采信的东西

网上关于 Ark 视频计费的 **AI 生成 SEO 文章数字大量互相矛盾**。已知一例：某篇同时声称
"5 秒 720P 扣 1200 tokens"和"10 万免费 tokens 约可生成 20 条 10 秒视频"（=5000 tokens/10s），
折算下来一条 5 秒视频只要 1.7 分钱——不可能是真的。

**规则：只采信控制台与官方文档；第三方文章只能当线索，不能当价格依据。**
