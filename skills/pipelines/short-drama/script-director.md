# 剧本导演 — 短剧流水线

## 何时使用

规格锁定之后。把创意变成可分镜的剧本与场次表。

## 前置

| 层 | 资源 | 用途 |
|---|---|---|
| 上游工件 | `delivery_spec`（`spec` 阶段产出） | 目标时长与音频路线 |
| 表 | `script` / `scene` | 落剧本与场次 |
| 工具 | `pipeline/stage_script.py` | 生成 + 版本管理 |
| 提示词 | `pipeline/prompts/script.md` | 交给模型的指令 |
| 知识 | `knowledge/01-制作方法/剧本规范.md`、`竖屏短剧结构模板.md` | 结构依据 |

## 流程

### 1. 先定结构，再写字

竖屏短剧的节奏与横屏完全不同。**前 3 秒决定生死**：

```
0-3 秒    钩子      必须是一个"发生了什么"，不是铺垫、不是介绍
3-15 秒   建立      交代关系与处境，用画面不用台词
15-60 秒  升级      冲突逐级加压，每 10 秒要有一次新信息
60-75 秒  高潮      最贵的那几个镜头拍这里
75-80 秒  扣子      给**新信息**，不是"事情没说完"
```

**扣子的判据**：观众看完的反应应该是"啊？"，而不是"哦，还没完"。
"事情没说完"是偷懒，"冒出个新东西"才是钩子。

### 2. 台词要短，能演的别用嘴说

| 规则 | 判据 |
|---|---|
| 每句 ≤ 12 字 | 数得出来。竖屏字幕一行放不下更多 |
| 动作代替台词 | "他把化验单揉成一团" > "我现在很生气" |
| 标点参与节奏 | 叹号加强、省略号造悬念、破折号拉长元音、逗号自然停顿 |

**标点那一条不是文学修辞，是技术参数**——如果走模型原生音频，
标点直接控制模型的停顿与语气。

### 3. 生成与版本管理

```powershell
python pipeline\stage_script.py --episode-id 1 --brief "一个关于化验单的悬疑短剧"
```

重跑会新增版本并保持 `script.is_current=1` 只有一条，旧版保留。
**不满意就重跑，不要手改数据库。**

### 4. 自查

```sql
SELECT seq, beat, duration_s, location, summary FROM scene
 WHERE script_id = (SELECT id FROM script WHERE is_current=1) ORDER BY seq;
```

## 常见陷阱

- **前 11 秒在铺垫。** 竖屏没有这个耐心
- **用旁白解释剧情。** 观众是来看画面的
- **台词写成长句。** 一行字幕塞不下，配音也赶
- **扣子只是"没说完"。** 必须给新信息
- **各场时长合计远低于目标。** 后面分镜会凑不满，或者硬凑出一堆废镜
- **改了剧本不重跑后续阶段。** 分镜与提示词会引用旧场次

## 质量门禁

- `script.is_current=1` 有且只有一条
- 每个 `scene.beat` ∈ {钩子, 建立, 升级, 高潮, 扣子}
- `scene.seq` 从 1 连续
- 各场 `duration_s` 合计与 `target_episode_seconds` 偏差 ≤ 20%
- 台词逐句 ≤ 12 字（可脚本化核对）
- 第一个场的 `beat='钩子'` 且 `duration_s ≤ 5`

## 门禁提醒（绑定）

本阶段有人工门禁。做完后**结束回合**，等人批。

批准：`python pipeline\run.py --episode-id N --approve script --note "钩子够狠"`

**剧本决定后面的一切。** 为了省时间冲过这道门，产出的是没人想看的东西。
